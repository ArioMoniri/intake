# Evidence — INT-314 · The four spoken fields become per-locale maps, and the clamp that stood in for them is removed

Epic E03-protocols · phase P1 · `sec_row: protocol-registry` · depends on INT-297 (done).

`confirm_tr`, `action_tr`, `do_nots_tr` and `ask_one_tr` become maps keyed by locale on
the same schema as INT-297's five, with `tr` required. They are the *action* half of a
red-flag script, so this is where CLAUDE.md invariant 10 — *"scripted protocol questions,
red-flag action scripts and validated instruments are spoken verbatim from `text_tr`"* —
stops holding for only half of a RED rule. `action_tr` is the field that closes it.

INT-297 left them fail-closed rather than ignored: `protocols.pack_locale.selectable_locales`
clamped any pack carrying one of the four to `tr`. **This issue removes that clamp**, and
the removal is the third acceptance clause, not a side effect.

**The headline is §5: every one of the 58 authored spoken fields in the tree — authored
bytes and `expand_tr` expansion both — is unchanged, stated as comparator output.**
