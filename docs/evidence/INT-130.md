## What the tests pin

- **Nav map = 02 §4, exactly**: the route file list is asserted *equal* to
  the map (both directions — a missing route fails, and so does any stealth
  surface beyond the map), including `me/learned`.
- **Consent-gated wellbeing**: one pure rule (`visibleTabs`); hidden means
  absent from the rail. Mutation proof above.
- **tr-first i18n**: `en` must mirror `tr` key-for-key; no empty strings; no
  fully-uppercase strings (İ/ı rule); no `sen`-register pronouns; tab labels
  in the layout must come from `t()`, never literals.
- **Dynamic type**: body 17 at 1.0, linear to the 2.0 cap (02 §8.2), floor at
  0.5, cap applied in exactly one function; 1.4× line height per role.
- **Accessibility floors as computation, not review**: WCAG AA contrast
  (≥4.5:1) is computed in-test for every text/ground pair in both palettes.
- **RED discipline (02 §5.3)**: the emergency hex pair appears nowhere
  outside `theme.ts`.
- **Synthetic-only test accounts**: fixtures reject anything TCKN-shaped
  (`\d{11}`); dev accounts render only behind `__DEV__` and only on the
  welcome screen (asserted over the route tree).
