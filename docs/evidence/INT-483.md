# INT-483: self/proxy answering — ADR-040 and the subject_role addressing mechanism

**Epic:** E03-protocols · **Phase:** P1 · **Sec-Row:** `clinical-content` · **GitHub:** #826 ·
**Depends on:** INT-448, INT-223 · **Branch:** `int-483-self-proxy` · **Date:** 2026-10-04

## Scope, stated once

Owner decision **D24, answer 1Y** (3 Oct 2026; INT-470, PR #804): in a proxy session, where a parent or carer answers for the patient, every self-addressed question is reworded for the patient ("Çocuğunuz…") or skipped. The child and carer paths stay closed until that mechanism exists.

The legal bounds come from **LD-02** (INT-471, PR #809, status `proposed`, synthetic and test use only):

- majority is the eighteenth birthday;
- only a velâyet holder or a vasi acts for a minor;
- an adult with discernment answers alone;
- the carer rule is a product rule, not the law;
- HB-L20 stays open for counsel.

This issue builds the mechanism and **leaves the content empty**:

- no pack gains a proxy block;
- no item is chosen for rewording or skipping;
- no proxy sentence is written.

Those are D18 clinical decisions and arrive in a separate clinical decision record. ADR-040 records the decision: `docs/adr/ADR-040-subject-aware-addressing-for-proxy-sessions.md`.

## Acceptance (verbatim from docs/backlog/issues.yaml)

- ADR-040 (docs/adr) records the decision, the mechanism and what stays closed; cites D24, LD-02, and the CD-110/CD-103/CD-104 items that depend on it (T11-T15, cluster-wave-b #L77 #L105 #L117, INT-353 #L310, pedodonti/ortodonti/Evde Sağlık)

## What was built

| Layer | Change |
|---|---|
| DSL | `protocols/addressing.py`: `Addressee` (patient, the default, or speaker), `Addressing` (self or proxy), and `ProxyAddressing`, which either rewords with its own verbatim `ask_tr`/`follow_up_tr`/`confirm_tr` or sets `skip: true`, never both and never neither. `Slot.addressee` and `Slot.proxy` are new. A speaker slot with a proxy block is a schema error. A rewording that does not mirror its self form's spoken fields is the validator finding `PROXY_TEXT_MISMATCH`. Proxy texts are scanned for numerals (invariant 22) and join the INT-297 locale intersection. |
| Compiler | `compile/proxy_path.py`. On every path it refuses `PROXY_SKIPS_RED_FLAG_PROBE` and `RED_FLAG_PROBE_SPEAKER_ADDRESSED`. On the proxy path it also refuses `PROXY_ADDRESSING_MISSING`, `PROXY_TEXT_INCOMPLETE`, `RED_FLAG_PROBE_GATED_ON_SUBJECT_ROLE` (transitive, and covering speaker slots), `PROXY_GATED_ON_SUBJECT_ROLE`, `PROXY_SKIP_CLOSES_GATE` and `PROXY_ADMINISTERS_INSTRUMENT`. `resolve_protocol`/`compile_bundle` take `addressing`, and the CLI takes `--addressing`. The proxy document carries the proxy text in the spoken fields and marks skipped slots, so its pinned hash covers what a proxy hears. The proxy bundle's clips and Questionnaire leave skipped items out, and the bundle is written to `dist/<pack>/proxy/`. |
| Schemas | `AnswerState.NOT_ASKED_PROXY`, the eighth state; OpenAPI and TS regenerated. |
| Runtime | `build_residency_tr_session` and `build_typed_session` require `addressing` with no default and pass it to the engine. `IntakeEngine(..., addressing=...)` refuses a role that is not the document's. Skipped steps start `NOT_ASKED_PROXY` and are never offered, bound or overlay-confirmed. `IntakeEngine.proxy_skipped` lists them. They count against must-ask coverage. |
| Note | `NoteGapReason.NOT_ASKED_PROXY` (`not_asked_proxy`) and `NoteGap.not_asked_proxy(step_id)`. The clinician copy key is `previsit_note.gap.not_asked_proxy`. Production copy lives in `docs/legal/strings.yaml`, which does not exist yet, so the note fails closed. The synthetic fixture string sits in `tests/fixtures/legal/strings.synthetic.yaml`. |
| Docs | ADR-040, a note in `files/12` §2.2 and `files/13` §9.3, and the `docs/index.md` link. |

A **red-flag probe** is any slot read by a red-flag rule's `when` or `tense_anchor`. That covers the pack rules after composition and the `base.life_threat` rules, drafts included. Every slot of the files/04 §1 `red_flags` section is also a probe.

## Findings (not fixed here; routed)

1. **The carer path is open at the profile layer.** INT-133's `resolve_profile_flow` admits an acknowledged adult companion as `proxy_report`. The mobile app's own TS question set is outside the compiled packs (INT-096). On the compiled-pack route the carer path is closed: no proxy bundle compiles, and the engine refuses a proxy session on a self document. Closing the profile-layer and app routes is a decision for the files/06 §6 owner, and LD-02 already names the conflict (`carers.conflict_for_06_owner`).
2. **An in-session contradiction is unhandled.** A session's addressing is fixed when the engine is built. A speaker who answers "yakınım adına" in a session started as self still meets only the CD-01 chest-pain stop-gap. Ending such a session and restarting it on the proxy document is runtime behaviour this issue does not specify.
3. **The subject-role literals disagree.** `base.intake` offers the choices "kendim için" and "yakınım adına". Its gates compare against `'kendim'` (`identity_check.proxy_reported`'s `ask_if`, and the review-queue `cluster/mental_health.yaml` twice) and against `'yakınım adına'` (the CD-01 stop-gap). No `vs.subject_role` definition is committed. If the slot binds the choice text, `subject_role != 'kendim'` is TRUE for a self answer, and the proxy question is put to a patient answering for themselves. This is pack content under CODEOWNER review, so it is reported and not edited here.
4. **The RED action script in a proxy session.** The action and the UNKNOWN branch's one question ("Şu anda hastanede misiniz?") speak to whoever holds the device. In a proxy session that person's location sets REMOTE or ON_SITE for the patient, and ON_SITE removes 112 (invariant 21). This belongs to the RED axes and to HB-C9's open proxy question (files/02 §5.3), not to slot addressing. ADR-040 records it as a condition: before a proxy path opens for a chain with an active RED rule, the decision record states the proxy reading of the location question and the action.
5. **Safeguarding probes.** `rf_suicidal_intent` and `rf_suicidal_ideation_passive` sit in the `red_flags` section. A pack may therefore not skip them in a proxy session, while INT-133's regime does not ask safeguarding of a proxy at all (files/13 §13). The decision record must word them consistently with files/13 §13 and HB-C8.

## What stays closed

- **The proxy path of every pack in the tree.** No pack carries proxy content.
- **The screening section's instruments.** Every pack inherits `base.intake`'s PHQ-2, GAD-2, PHQ-9 and GAD-7. The proxy path stays closed past the slot content until the engine implements files/12 §2.2 (`InstrumentNotScored` for a non-self item) and a decision says how a proxy session treats screening.
- **What the content PR must also do.** When the D18 decision record lands, the PR that writes it into the packs must:
  - drop the CD-01 `skip_if` stop-gap;
  - add English mirror keys `<section>.<slot>.proxy.<field>`;
  - edit the closed-state pin test.
- **The child path.** INT-223 refuses every subject under eighteen before attribution, and the guardian-path HB-L20 rows stay awaiting-human.
