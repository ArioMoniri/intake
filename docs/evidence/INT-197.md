## What the tests pin

- **Fail-closed dev auth**: tokens only from `INTAKE_DEV_TOKEN_PATIENT` /
  `INTAKE_DEV_TOKEN_ADMIN`, no in-code default; either unset → every /v1
  request is 503 and `/readyz` reports `dev_auth: error`. Wrong/missing
  bearer → 401. Every response carries `X-Intake-Auth-Tier: dev`.
- **Invariant 18 (no new persisted fields)**: a visit is one `sessions` row
  (`protocol_id = previsit.dev.visit`) plus three plain `visit.*` slots; a
  note is one `notes` row; sending is a `shares` row; documents are
  `documents` rows referencing the INT-034 object store. Zero schema
  changes.
- **Invariant 14**: `notes.payload` at rest is exactly the four-key
  EncryptedField envelope (asserted against the raw row on SQLite and on
  live postgres); plaintext never appears in the column.
- **Invariant 4**: every clinical read/list/create/share/document operation
  checks a consent scope (`core`, `documents`, `share:previsit_note`) and
  appends to the INT-016 hash chain; refusals disclose nothing and the
  chain verifies (`verify_entries`). The INT-034 store's own audit entries
  ride the SAME chain, serialised behind one lock (two chain writers with
  private heads would fork it).
- **02 §5.1 share semantics**: scope-off sections are excluded from what the
  clinic side sees, never from the patient's own view; re-saving revokes
  live shares (draft takes the note back); the admin account reads a note
  only through a live, unexpired share and can write nothing.
- **INT-034 posture end to end**: declared sha256 recorded as UNVERIFIED
  provenance; ingest recomputes the digest server-side, runs the AV hook
  (503 fail-closed without a scanner; INFECTED retained under `infected/`,
  409 on any URL attempt), promotes quarantine→clean; download URLs only for
  clean objects; no filename parameter exists anywhere.
- **Invariant 15**: /healthz /readyz /metrics /version via
  `intake_platform.health`; http metrics via `mount_http_metrics` (both
  families pre-catalogued — no metrics_catalog.yaml change needed);
  security headers on every response.
- **Tenant isolation twice**: explicit tenant predicates proven on the
  SQLite unit lane; FORCE RLS + the `app.tenant_id` GUC proven on live
  postgres.
