# INT-594 — Bugün is true: no unsourced duration, and the focus follows the delivered note

GitHub #1007 · Sec-Row: `mobile` · branch `int-594-today-truthful` from main `5d6984a7`.
From the INT-502 captures on build 7.

## 1. The defect

An OTP account's Today screen was stuck on "Muayeneye hazırlanın (≈3 dk)" over a
"%36 Vizit hazırlığı" gauge. There were three faults:

1. **The state was read raw.** The hospital feed carries no note state, so `syncVisits` in
   `lib/auth/api.ts` sets `noteStatus: null` on every visit. `today.tsx` chose its CTA from that
   value alone. So it never reached "Devam edin", even with answers on the phone, and never saw a
   note the server had confirmed (INT-587). The visit detail already used `effectiveStatus`;
   Bugün did not.
2. **"≈3 dk" was never measured.** INT-139 set the rule: a duration is a measurement in
   docs/evidence, with a date and a named corpus, never in patient copy (invariant 20). No such
   measurement exists for intake. A store frame of this screen would carry the figure.
3. **The gauge was a bare percentage over a false denominator.** It divided answered questions
   by the pack's question count. The flow asks conditionally (`askIfMet`), so the denominator
   includes questions the patient may never be asked. 100 % could be unreachable, and the
   number was a score with no unit.

## 2. What changed

| file | change |
|---|---|
| `apps/mobile/src/lib/today.ts` (new) | `todayFocus(visits, notes, isDelivered)`: the state of each visit is `effectiveStatus` (its ladder step, the draft on the phone, and a sent note only once the server confirmed it). The first visit still to prepare wins: `prepare` (no note) or `continue` (a draft). Otherwise the next visit with a confirmed delivery is `sent`. Otherwise `none`. A delivered visit is never hidden behind "Planlanmış bir vizitiniz yok." |
| `apps/mobile/src/app/(tabs)/today.tsx` | Reads `todayFocus` and the outbox (`useDeliveries()`). It renders the "Sıradaki vizit" kicker, the hero card with the derived status chip, and `t(focus.cta)`. The gauge is gone. |
| `apps/mobile/src/lib/intake/delivery/store.ts` | `allDeliveries()` / `useDeliveries()`: every outbox item at once, so one screen can read several visits. The map is replaced on every change, so it is a stable snapshot. |
| `apps/mobile/src/components/PrepGauge.tsx` | Deleted: it had no other user. |
| `tr.ts` / `en.ts` | `today.prep` and `today.prepareCta` are removed. The prepare CTA is the visit's own `visit.prepare` ("Muayeneye hazırlanın" / "Prepare for the visit"). New: `today.openCta`, "Viziti açın" / "Open the visit". |

## 3. Tests

`apps/mobile/src/lib/today.test.ts`, 15 tests.

**Focus.**
- A feed visit with nothing on the phone gives `prepare`.
- With answers it gives `continue`, the state build 7 never reached.
- **Near miss:** a note the patient sent but the server has not confirmed stays a draft.
- **Near miss:** a confirmed delivery without the patient's send is not a sent note.
- A confirmed note gives `sent`, with "Viziti açın".
- A visit to prepare comes before a delivered one.
- A delivered visit is never `none`.
- The dev fixtures' ladder is kept: a draft continues, and a filed-only list is `none`.

**Copy.**
- No tr or en catalogue line carries a duration or an approximate figure. The pattern is
  `≈`/`~` before a digit, or a number followed by sn/dk/dakika/min/sec.
- **Near miss:** the pattern bites on "Muayeneye hazırlanın (≈3 dk)", "Prepare for the visit
  (≈3 min)" and "Yaklaşık 3 dakika sürer", and not on the fix.
- "Viziti açın" / "Open the visit" are pinned.
- `today.prep` and `today.prepareCta` are gone from both catalogues.

**No percentage.**
- The screen uses `todayFocus(`, `useDeliveries()` and `t(focus.cta)`, and never compares a raw
  `.noteStatus` (near miss: that is what kept it on "prepare").
- It renders no gauge and no fraction, and PrepGauge.tsx is gone.
- No shipped module formats with `style: "percent"`. **Near miss:** the pattern sees the
  formatter the gauge used.
