## Reachability

node-forge 1.4.0 is in pnpm-lock.yaml only under @expo/cli 57.0.19 and
@expo/code-signing-certificates 0.0.6. Reading @expo/cli 57.0.19's published
`build/` tree (the npm tarball), node-forge is required from two modules only:

- `src/utils/codesigning.js`. The `expo start` dev server's
  `ExpoGoManifestHandlerMiddleware` uses it to sign development manifests,
  and `api/user/user.js` reaches it on `expo logout`, which removes the
  development code-signing directory.
- `src/run/ios/codeSigning/Security.js`. `expo run:ios` uses it to read the
  developer's keychain certificates when building for a device.

So the build steps that touch node-forge are `expo start`, `expo logout` and
`expo run:ios` on a developer machine. `expo export` does not, and
`git grep node-forge -- apps packages services` (lockfile excluded) finds no
import in app or service code.
