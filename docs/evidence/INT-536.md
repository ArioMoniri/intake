## 5. F8 — the loader reads ADR-035's bound class

`SyntheticLegalIndex` and `SyntheticConsentTextCatalog` take an optional `bound:
ModelLanesReader`. Every `entry()` reads it fresh, as the bytes are read:

| case | result |
|---|---|
| no store configured | serves; nothing can be bound, so the declaration governs |
| unbound, or bound `synthetic` | serves |
| bound `real_phi`, declared `synthetic` | `SyntheticLegalTreeRefusedError`. `effective_data_class` reads the mismatch as `real_phi`; the catalog raises `ConsentTextInvalidError`, so no grant binds |
| record unreadable (`ModelLanesUnavailable`) | refuses: the class cannot be known |

Wiring:
- `ApiSettings.model_lanes_redis_url` comes from `INTAKE_MODEL_LANES_REDIS_URL`, the same
  store the console writes. The staging compose already sets it.
- `state.consent_catalog_for` hands the catalog that store.

`tests/legal/test_synthetic_bound_class.py` covers:
- each case in the table, including a class bound after the loader was built;
- the settings read;
- the API wiring, with the store swapped for an in-memory one bound `real_phi`;
- the no-store near miss.
