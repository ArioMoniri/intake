### Deploy
The deploy ran `init.sh` and then `deploy.sh`.
- `init.sh`:
  - generated every secret into `/etc/intake-staging/.env` (0600 root);
  - brought up OpenBao in server mode with the transit KEK;
  - ran alembic from 0001 to 0012;
  - re-keyed the 4 database roles away from their committed dev passwords.
- `deploy.sh` brought up the api, postgres, redis, openbao, minio and caddy containers, and all six report healthy.

Two first-run failures were fixed on the PR branch:
- SSM runs `sh`, so the scripts now run under bash.
- OpenBao 2.6.3 refuses `disable_mlock`, so the line was removed and a swap guard was added (#549).
