## 1. What this is, and what it deliberately is not

The inbound counterpart to INT-160's outbound sender: the direction a Turkish hospital
information system (HBYS/SBYS) feeds a result **back** to the patient's record, over the
three common interfaces — HL7v2 (ORU^R01), a file drop, and FHIR (reused from INT-161, not
re-implemented) — plus the USVS (Ulusal Sağlık Veri Sözlüğü) mapping to
`packages/clinical-schemas`.

Like INT-160 and INT-210, the **mechanism ships complete and the human-legal content fails
closed**. The USVS *national code bindings* are a clinical judgement no committed source in
this repository vouches for, so every one is `draft_needs_source`, the loader refuses to
serve it, and an inbound lab resolves to an item with **no code** rather than a guessed one.
The KTS pack refuses to call itself complete while the SBSGM-published document list is
uncommitted. The inbound-source registry ships with **zero rows**, so every message refuses.
These are the fail-closed states, not gaps (invariant 17). The open asks are recorded in
`docs/backlog/blockers.md` (three INT-162 rows) and cross-referenced to
`files/HUMAN_BLOCKERS.md` (HB-A5, HB-A15; new code-binding and KTS-list asks flagged for the
coordinator to allocate an HB id, per the parallel-artifact rule).

Reused framework (INT-160/161), not forked: `ConnectorAdapter`/`ClinicalPayload` redaction
discipline, the id-shape validators and registry pattern from `destinations`, the
`ConsentGate`/`ConsentVerdict`/`ConsentDenied` seam and the hash-chained `AuditChain`, the
`ExtractedRecordItem` INT-031 transport type (never a guessed code), and the FHIR adapter.

New pieces: `intake_connectors.inbound` (message, observation, source registry),
`.hl7v2` (ER7 ORU parser), `.filedrop` (file-drop channel + CSV), `.usvs` (mapping tables +
mapper), `.ingest` (consent + audit orchestrator), `.kts` (pack generator), `.dpa`
(processor-role clause references); data `usvs_map.yaml`, `kts_requirements.yaml`,
`infra/connectors/inbound_sources.yaml` (zero rows); generated `docs/regulatory/kts_pack.md`;
one catalogued metric `connector_inbound_messages_total`.

## 2. Invariants held (tests enforce)

- **Inv 14** — a message is data, never a command: parsing is a table lookup on the segment
  name (`OBX` read, every other segment inert), delimiters read from MSH-2, escapes decoded
  to literal characters. `test_an_unknown_segment_is_inert_and_changes_no_observation`,
  `test_delimiters_inside_a_value_are_decoded_as_characters_not_structure`. A `lan_plaintext`
  source needs a separate recorded approval (`test_a_plaintext_lan_source_without_its_own_approval_is_refused`).
- **Inv 1** — an inbound message may carry candidate_flags only: `InboundObservation` and the
  mapped `ExtractedRecordItem` have no field a triage level could occupy
  (`test_the_mapped_item_has_no_field_a_triage_level_could_occupy`).
- **Inv 4 / 6** — ingest clears a consent scope and is audited as ids only
  (`test_ingest_writes_an_audit_entry_naming_ids_only`, `test_ingest_refuses_when_consent_does_not_stand`);
  the message body redacts itself and no value reaches an error
  (`test_the_message_body_redacts_itself_in_repr`, `test_a_parse_error_carries_no_value_from_the_message`).
- **Inv 17** — the USVS code bindings are `draft_needs_source` and never served; the KTS pack
  fails closed. Represented by absence, not a placeholder token (the sole `TODO:` exception is
  scoped to `packages/protocols/**`, which this is not).
- **Inv 22** — a value crosses as a `Decimal`, grouping refused, unit token preserved and never
  converted (HB-C24): `test_a_grouped_number_is_never_silently_reinterpreted`.

## 6. Human-blocked (see docs/backlog/blockers.md, INT-162 rows)

1. **USVS code bindings** — physician of record + clinical biochemist + DPO/counsel: which
   committed, dated USVS dictionary do inbound codes map to? Until answered, all code
   bindings stay `draft_needs_source` and nothing resolves to a code.
2. **KTS required-document list** — owner + counsel: the current SBSGM-published list, so the
   pack can enumerate every required artefact. Until then `is_complete()` is `false`.
3. **Executed processor-role DPA + first inbound source** — owner + counsel + `platform_owner`:
   the destination-half analogue of HB-A15, plus HB-A5 (which interfaces a hospital exposes).
   Until then `inbound_sources.yaml` holds zero rows and every ingest refuses.
