## What is EMPTY, and why — read this section first

Two things this issue built the mechanism for and **must not** fill in. Both are empty in the
tree, and in both cases the empty state **refuses** rather than quietly succeeding.

### 1 · The crisis lexicon — HB-C8

`files/protocols/base.life_threat.yaml`, `rf.crisis_disclosure_signposting.source_gap`,
verbatim:

> *"(1) The crisis LEXICON itself — the deterministic Turkish phrase list behind
> `transcript.crisis_lexicon_hit` — does not exist and must be clinician-authored, not
> model-generated."*

So **no Turkish crisis phrase was written**, anywhere: not in the package, not in a fixture,
not in a comment. `unauthored_lexicons()` ships two lists in the `UNAUTHORED` state — the
crisis list and the four files/03 §4.7.5 marker lists — each naming **HB-C8** and the refusal
code it raises with.

The distinction the issue turns on is that **an empty list and a missing list are
indistinguishable in production, and only one of them is honest**. Both never match. So the
mechanism refuses to let them look alike:

| | proof |
|---|---|
| an *authored* lexicon with **no entries does not construct** | `test_an_authored_lexicon_with_no_entries_cannot_be_constructed` — and the mirror case, an unauthored lexicon carrying entries, is refused too |
| an *unauthored* lexicon **raises** when scanned, naming HB-C8 | `test_scanning_an_unauthored_lexicon_refuses_rather_than_reporting_no_hits`, with the positive control on the same line: an **authored** lexicon returns `()` for a non-matching turn, so "no hits" and "no list" are different observable states |
| the refusal reaches the caller of the **bypass**, not only of the lexicon | `test_the_bypass_refuses_while_the_lexicon_is_unauthored` |
| there is **no phrase in the source tree at all** | `test_no_lexicon_entry_exists_anywhere_in_the_shipped_package` walks the package's AST and asserts no `LexiconEntry` is constructed in it. A future edit that populated the constant would pass every other test by making the lexicon authored; this one would fail |
| the marker aggregate does not fake a measurement either | `test_an_unauthored_marker_lexicon_reports_its_status_and_no_zero_counts` — the section carries `lexicon_status: "unauthored"` and **no** `marker.*` keys, because `hopelessness: 0` from a list nobody wrote is a measurement nobody made |

There is also no `false` to hand the rules engine: the rule gates on
`transcript.crisis_lexicon_hit == true`, and while the lexicon is unauthored the scan
refuses, so the runtime never asserts "no crisis phrase was said" on the strength of a list
that does not exist.

The synthetic phrases the suite uses — `sentetik tetik` (the positive), `sentetik yakin
tetik` (the near miss), `sentetik belirtec` and `sentetik ikincil` (the marker entries) —
follow `tests/sim/personas.py`'s `sentetik_tetik` / `sentetik_yakin_tetik` convention. They
carry no affective or clinical vocabulary at all, deliberately: a synthetic phrase that
happened to read like a real marker is a phrase somebody eventually copies.

### 2 · The C-SSRS instrument — HB-L2 (and the escalation policy, HB-C8 again)

The acceptance says hits route to the **C-SSRS path**. C-SSRS is licence-**BLOCKED**: Clario
holds the exclusive RFMH electronic licence, and the only Turkish validation is adolescents
12–18. So what exists is the deterministic **route**, and a refusal at the far end:

- `CrisisRoute` resolves — rule id, instrument id, entry ref, turn ref, section ref, match
  position, `consent_independent: true`;
- `open_crisis_path(route)` is typed `-> NoReturn` and raises `InstrumentLicenceBlockedError`
  carrying **both** codes: `INSTRUMENT_LICENCE_BLOCKED` (HB-L2) and
  `CRISIS_PATH_POLICY_MISSING` (HB-C8, the files/04 §4.2 escalation policy — responder,
  abandonment handler, means restriction, safety planning — which the protocol compiler
  already refuses with under the same name). Closing HB-L2 alone must not look like closing
  the crisis path, so neither code hides behind the other.

**No fallback screener**, deliberately. files/04 §4.2: the crisis response is deterministic
signposting, *"not a screener, not a score"*, and *"a screener here would need the licence"*.
`test_there_is_no_fallback_screener_behind_the_refusal` asserts the return type is `NoReturn`
and that **no other instrument id** (PHQ-9, PHQ-2, GAD-7, GAD-2, HAQ-DI, ASQ) appears
anywhere in the package.

`LICENCE_BLOCKED_INSTRUMENTS` refuses C-SSRS and WHO-5 **by name**, the posture `consent.py`
takes for `lane:acoustic`: a licence table is data, and data can be stale or injected, so
`resolve_instrument("C-SSRS", {"C-SSRS": "GO"})` still refuses. Its positive control —
`resolve_instrument("sentetik-arac", {"sentetik-arac": "GO"})` returns — is in the same test,
because a gate that refuses everything proves nothing.

### The lane, and the bypass, are two different things

files/03 §4.7.5 puts both in one row, and conflating them is the defect the design guards
against:

- the **lane** is consent-gated on `lane:linguistic` (files/06 §2 — one of the two lane
  purposes that actually exist, which is why this lane resolves where `asr_quality` and
  `engagement` cannot, HB-L23). It drains final transcripts, folds each into the aggregate
  for **its own section**, and writes `linguistic_markers{}` through the framework's one
  writer;
- the **bypass** is not the lane. files/04 §4.2 defect 3: *"a consent-independent crisis
  response … the people most likely to decline are the people most needing to be caught."*
  `test_the_bypass_routes_with_no_consent_and_no_lane_registered` reaches it with nothing
  granted, no lane registered and no scheduler at all;
- and the two do not leak into each other:
  `test_a_crisis_hit_never_reaches_observer_state` feeds the same transcript to both, and the
  aggregate mentions neither the rule, the instrument nor the word "crisis".

### "Deterministically" — the load-bearing word

- `CrisisBypass.scan` is an ordinary function of one value: not awaitable, no injected scorer,
  no callback (`test_the_bypass_is_not_awaitable_and_takes_only_data`).
- Fifty scans of the same transcript give the same route; two bypasses built from the same
  entries in **opposite order** give the same route
  (`test_the_route_is_deterministic_for_the_same_transcript`).
- `test_no_model_sits_in_the_crisis_path` walks the package's AST and asserts it imports no
  model, no client and no clock — `random`, `secrets`, `time`, `torch`, `transformers`,
  `numpy`, `httpx`, `openai`, `anthropic`, `intake_platform.llm`,
  `intake_voice_runtime.talker` and `protocols` are all absent. A lane that called an LLM
  here would be a defect, so the package cannot name one.
- Matching is by **whole token sequence, never substring** — the `üre` rule of invariant 22,
  and the `ANALYTE_NAMES` precedent. `test_a_token_sequence_is_never_matched_as_a_substring`
  is the control; an entry whose "token" is a whole phrase does not construct.

### Markers aggregate per section

`TranscriptTurn.section_ref` carries the section, so `LaneContext` did **not** have to be
widened (the issue's instruction, and the right answer: the engine already knows the section
when it finalises a transcript). Marker keys are `section:<section_ref>`, so a second window
updates a section rather than appending to it, which is what makes
`ObserverStateBuilder.apply`'s `update()` merge correct.

`test_markers_aggregate_per_section` runs two windows across two sections and asserts neither
section's counts bleed into the other.

### Prosody, and what is *not* in it

`speech_rate_syl_per_s`, `articulation_rate_syl_per_s`, `pause_ratio`, `span_ms`,
`phonation_ms`, `pause_ms`, `words`, `syllables`, `turns` — from word timestamps only.

- **No threshold is invented.** A "pause" defined as a gap longer than *N* ms needs an *N* no
  human has supplied (HUMAN_BLOCKERS rule 1). `pause_ratio` is inter-word gap time over the
  turn's span, which needs no cut-off at all.
- **No reference range.** files/03 §4.7.6 wants each statistic shown with a population
  reference range; those are clinical values nobody has supplied, so the lane emits the
  measurement and no range. A missing range is visible; an invented one is not.
- **An undefined ratio is omitted, not zeroed** — a rate over a zero-length span is not `0.0`
  (`test_a_turn_with_no_words_counts_as_a_turn_and_measures_nothing`).
- Turkish syllables are counted by vowel, which is orthography rather than a clinical
  judgement; `tokenize_tr` handles `I`/`İ`, which `str.lower()` does not, and a lexicon that
  missed that would silently never match a capitalised utterance.

## What was deliberately not done

- **The framework was not touched.** No file under `observers/` outside the new
  `linguistic/` subpackage changed — including the package `__init__.py`. Two other agents
  are working in this tree and that file is the one every sibling lane (INT-111, INT-113,
  INT-114, INT-115) will want to edit; a lane is imported from
  `intake_voice_runtime.observers.linguistic` and needs no re-export. **One consequence to
  record:** the framework `__init__.py` docstring still says *"it contains no lane"*, which
  is now stale by one word. It is a one-line correction and it belongs to whoever next has
  that file uncontended — flagged here rather than edited under a concurrent writer.
- **`LaneSignal` emission into the hash-chained event log** (files/03 §4.8, invariant 20).
  INT-110's evidence anticipated it landing "with INT-112", but it is not in this issue's
  acceptance and it cannot be built from here: the emitter is the *scheduler* (framework) and
  the sink is the audit chain in `intake_platform`, both outside this change's ownership. The
  lane produces the payload the signal would carry, so the wiring is now unblocked.
- **A crisis-lexicon YAML schema, a lexicon file, or an escalation-policy file.** The INT-255
  precedent applies verbatim: inventing the schema for the missing thing *is* designing the
  missing thing, which HUMAN_BLOCKERS rule 2 names as the way a blocker becomes a defect. The
  refusals cite HB-C8 and HB-L2 by name so that closing them has an obvious landing site.
- **A metrics catalogue row.** `observability/metrics_catalog.yaml` is outside this change's
  ownership, and INT-110's position — count in process, emit nothing — is unchanged.

## The asks, for the humans named on the blockers

Neither is new; both are recorded here because this issue is the mechanism they will land in.

- **HB-C8** (clinician + owner) — *the crisis lexicon.* The mechanism is built and fails
  closed. What is needed is the clinician-authored Turkish phrase list, entry by entry, each
  with a sign-off ref, **and** the files/04 §4.2 escalation policy behind it. The landing
  site is `LexiconEntry` + a lexicon loaded outside this package (the lane package holds no
  file capability by design — invariant 13). Nothing here may be filled in by a model, a
  search tool or a learning proposal.
- **HB-L2** (owner + counsel) — *C-SSRS.* Until it is `GO` or dropped, `open_crisis_path`
  refuses. If it is dropped rather than licensed, the route's target changes and
  `CRISIS_INSTRUMENT_ID` is the single line that moves — but files/04 §4.2 forbids replacing
  it with a fallback screener, so the replacement is a decision, not an edit.
