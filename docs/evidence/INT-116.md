## What was built

- `packages/protocols/src/protocols/wellbeing.py`:
  - **Loader** (`load_instrument_registry`). It reads one file,
    `packages/protocols/instruments/tr/registry.yaml`. Every item, option and timeframe string must
    be verbatim in the committed snapshot the entry cites. The check is
    `protocols.source_snapshots.source_snapshot_problem`, the one the life-threat loader uses.
    It refuses any content or cut-off for an instrument whose licence is not `GO`, so C-SSRS and
    WHO-5 text cannot be committed at all.
  - **Licence → items → trigger → path** refusal order in `open_instrument`. Licence comes first,
    so a BLOCKED instrument is never looked up.
  - **Administration**: one item at a time, in order. The prompt hands over the registry's
    records by reference. The only answer is an option id; anything else raises `AnswerRefused`
    without quoting it.
  - **Cut-offs** (`Cutoff`): cascade, crisis trigger and severity. An active cut-off is an
    integer plus a verbatim-quoted source. A draft carries only the pending form and no number,
    and the engine refuses to apply it (`cutoff_unsourced`).
  - **Crisis path** (`CrisisPath.from_served`). It is built only from the served rule set, only
    around a consent-independent KIRMIZI rule whose gate reads `safety.self_harm_statement`. It
    takes no consent argument (files/04 §4.2 defect 3). An instrument with a crisis item does not
    open without a sourced trigger and a path (files/04 §4: never end on the item without the
    safety script).
  - **Outputs**: `ClinicianInstrumentRecord` (answers, total, band or refusal, crisis flag,
    `administration_mode`, `third_party_present`, `proxy_reported`); `to_screening_block` puts
    them into the note with the files/04 §4.3 qualifier "başka bir konuşmacı duyuldu";
    `PatientWellbeingView` has `status` only.
- `packages/protocols/instruments/tr/registry.yaml`: `instruments: []`. It has five
  `draft_needs_source` cut-offs: PHQ-2 → PHQ-9, GAD-2 → GAD-7, the PHQ-9 item-nine crisis trigger,
  PHQ-9 banding and the GAD-7 Turkish cut-off. None carries a number. The GAD-7 gap records
  files/04's Konkan 2013 value of 8 (not 10) as unsourced, because no snapshot of the study is
  committed.
- SENTETİK fixtures: `tests/fixtures/instruments/registry.yaml` and
  `tests/fixtures/protocols/sources/SYN-ANKET.txt`. Every string is invented nonsense
  ("mor kaplan", "sarı tebeşir"). None resembles any real item.

## Findings — what was refused rather than invented

1. **No Turkish item text exists in the repository.** files/00 §2 says the PHQ-9 Turkish PDF is
   "the only durable evidence. Archive it into the technical file today". It was never archived.
   Fetching it and transcribing items is exactly "never invent a Turkish item" done by an agent,
   so it was not done. HB-C29 asks for the snapshot.
2. **Every cut-off is unsourced.** files/04 §4's "Score ≥ 3" and "item 9 > 0" are blueprint
   text, not a committed guideline snapshot. All five are draft with the pending form.
3. **The C-SSRS leg of the title cannot exist** (HB-L2), and files/04 §4.2 says the crisis
   response is signposting, "not a screener, not a score". So the cascade ends at the
   consent-independent crisis rule, never at an instrument.
