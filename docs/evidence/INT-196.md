## Red run

Two genuine reds drove the pass (design-agent session, 2026-08-28):

1. The coordinator's FloatingTabBar v1 imported `BottomTabBarProps` from
   `@react-navigation/bottom-tabs`, which is not an installed dependency —
   Expo Router 57 vendors react-navigation. `tsc --noEmit` failed with
   TS2307 (cannot find module) until the component was rewired to
   `expo-router/js-tabs` types. This red is what forced the js-tabs
   architecture rather than a props-shim.
2. `e2e/nav.spec.ts` source-fact assertions failed against the new layout
   (native-tabs import expectations, five-section registration, label
   source) until updated to pin the js-tabs + `Tabs.Protected` shape; the
   native-tabs import is now banned by the same spec.

An apparent Inter font-weight regression during iteration was ruled out as a
Fast-Refresh measurement artifact by a full reload before any code change —
recorded here because a fix without that check would have been a fake.
