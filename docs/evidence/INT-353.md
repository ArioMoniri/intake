  the served drafts' own ids.

  - `resolve_branch` never returns a candidate;

    `pack_compilable`;
  - a candidate registered on purpose still raises `L0PackServedError`;
  - the review root and a symlink to it are refused;
  - near-miss control: roots named `reviewed`, `review_notes` and `packs` still load.
