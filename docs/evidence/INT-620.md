# INT-620 — iOS 27 SDK: adopt the UIScene lifecycle

## Acceptance

1. A build linked against the iOS 27 SDK launches instead of crashing in `_UIApplicationEvaluateRuntimeIssueForNoSceneLifecycleAdoption`.
2. React Native starts exactly once, in a window that belongs to a `UIWindowScene`.
3. Opened URLs and universal links still reach `RCTLinkingManager`.
4. The change is a config plugin, so every `expo prebuild` and every EAS or Xcode build carries it, with a test.

## Finding (18 Nov 2026, NoMac cloud Mac, Xcode 27.2, iOS 27.2 simulator)

A Release simulator build of `main` plus #1042 (bundle `com.ariomoniri.intakemobile`) crashed at launch. The crash report shows `EXC_BREAKPOINT` (SIGTRAP), raised from UIKitCore `___UIApplicationEvaluateRuntimeIssueForNoSceneLifecycleAdoption_block_invoke`, in `-[UIApplication workspace:didCreateScene:withTransitionContext:completion:]`. The generated `AppDelegate.swift` creates `UIWindow(frame:)` in `didFinishLaunching`, and `Info.plist` has no `UIApplicationSceneManifest`.

TestFlight build 8 was built with the same Xcode 27.2, so it is expected to crash the same way on a device running iOS 27.

With a `SceneDelegate` and a scene manifest added by hand to the generated project, the same build opened the Turkish welcome screen ("Önvizit … Telefonla devam edin"). Phone sign-in then failed closed on the simulator: "Uygulamanın bu sürümü henüz hizmete bağlı değil", because a simulator has no App Attest. No SMS was sent.
