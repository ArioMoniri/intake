How the writer stays a draft writer:

- **Allow-list.** Every request passes `asc_client.guard`, an allow-list of the reads and draft edits the writer makes. Each edit may carry only its own attributes.
- **Refused before sending.** Submissions, review submissions, release requests, phased releases, pricing, availability, deletes, version creation and the App Review contact and demo-account fields are all refused before anything is sent. Ten near misses in the tests check this.
- **Credentials at run time only.** They come from the owner's eas.json (`submit.production.ios`) when the command runs. `repr` hides them, and the log carries field names and HTTP statuses only.
- **No live run from here.** The writer was **not** run against App Store Connect from this branch. It authenticates with the owner's key and edits the owner's account, so the owner runs it after their own yes.
