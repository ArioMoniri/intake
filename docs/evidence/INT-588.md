# INT-588 — patient copy is true in the no-voice release build

GitHub #989 · Sec-Row: `mobile` · branch `int-588-release-copy-truth`, stacked on
`int-587-note-delivery` (INT-587 made "sent" mean delivered). From the independent legal review of
the store listing (B6 precondition and notes), 29 Oct 2026.

## 1. Why a release build was saying false things

Voice ships in a dev build only. `intake.tsx` gates the voice lane (`voiceEligible`) and the
dictation button (`VoiceNote`) on `__DEV__`, and INT-421 strips the voice lanes from the
production profile. So the build TestFlight and the App Store carry can neither speak to the
patient nor take dictation. Separately, two consent rows contradicted the docs/legal texts the
server serves on the synthetic host.
