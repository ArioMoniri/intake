**Why the components were ported rather than installed.** The console's CSP is
`style-src 'self' 'nonce-…'` with no `unsafe-inline` (admin-console row, invariant 48). The
originals are client components. Recharts and Motion both paint `style` attributes, and this
CSP refuses those. Astryx needs StyleX and a theme provider. Installing them would mean either
weakening the CSP or shipping charts that render unstyled. So the design was ported into
server-rendered SVG with geometry in attributes, and colour and motion went into a bundled
stylesheet. The page still ships **no client JavaScript** and **no new dependency in the
production bundle**. The only new packages are two dev dependencies for the test harness:
`axe-core` 4.13.0 (MPL-2.0) and `jsdom` 30.1.1 (MIT), with `@types/jsdom`.
`scripts/ci/check_licenses.py` reports `OK: every dependency licence is on the allow-list`
(1009 node packages).

## 2. Change

- **`src/ui/figure.ts`** (new). Reads a chart's magnitude back out of the string the page
  already prints (`"2311 ms"`, `"93 %"`). A bar therefore cannot disagree with the figure
  beside it. Anything other than one plain figure (unknown, grouped, a plain-space unit, a
  numeric "unit") returns `null` and draws no mark (invariants 17 and 22).
- **`src/ui/charts.tsx`** (new). `BarList` is a horizontal bar list with gradient fills by
  tone, a hatched fill for a stale reading, a grow-in animation and the printed figure at the
  row's end. `Gauge` is a radial ring with the printed figure beside it. Each is one
  `role="img"` whose accessible name reads the same figures as the table under it. They
  render only inside a tile's `ok` branch, so an unknown tile still carries no figure.
- **Charts placed where data exists:**
  - **Overview:** an error-budget gauge on each SLO tile (red when the budget is
    overspent), and probe latency by component, with stale readings hatched.
  - **Ops:** GPU utilisation and memory. Model-lane requests and p95 latency, which are the
    model lanes on main. Clip-cache hit-ratio gauge and manifest coverage.
  - **CI/CD:** recent run durations per workflow, coloured by conclusion, and the
    required-gate pass share per ref.
  - **Voice:** p50 and p95 turn latency per profile.
  - **Access:** has no quantity to chart, so it takes the navigation, card, table and form
    refresh only.
- **Not charted, and why.**
  - **Cost:** `src/cost` is a view-model with no rendered page on main.
  - **Model lanes:** the hosted-lanes page is PR #751, still open.
  - **Roadmap:** there is no roadmap page or data in admin-web.

  The primitives are shared, so each of those pages takes a chart in a line once it exists.
- **`app/refresh.css`** (new; imported after `console.css`). It adds:
  - the Astryx scales;
  - a segmented navigation rail. `nav.tsx` is unchanged and only restyled;
  - cards with a 2 px state accent and a soft elevation;
  - quieter table headers and row hover;
  - state dots and pills;
  - styled form controls for the four-eyes forms;
  - fact lists whose columns may shrink and that stack at ≤ 480 px, so nothing widens the
    page at phone width. Ids are not broken mid-word.

  No `text-transform`, no ellipsis truncation and no `break-all` are used. Strings ship
  pre-cased, as files/00_STATE requires (Turkish İ/ı), and the spec asserts it.

  Motion runs once, on load, and lasts under a second. The only repeating motion is the halo
  on a blocked release badge. `prefers-reduced-motion: reduce` removes every animation and
  transition.
- **`src/ops/tiles.tsx`.** A tile is now an `article`, no longer a `section`. axe found a
  pre-existing defect on main. A labelled `section` is a region landmark, and on CI/CD and
  Voice a tile is titled like its band ("Deploy gate" inside "Deploy gate"). That made two
  landmarks with one name (`landmark-unique`) on both pages, in both languages. The bands
  remain the page's regions.
- **`apps/admin-web/THIRD_PARTY_NOTICES`** (new). The notices for the ported works.

### CSP: unchanged and verified

`src/ops/csp.ts` and `proxy.ts` are untouched. The rendered pages were served from a scratch
server under the production policy (`default-src 'self'; script-src 'self' 'nonce-…'
'strict-dynamic'; style-src 'self' 'nonce-…'; …`). The stylesheets were served as a
same-origin file, as Next.js serves them. Chrome then showed:

- **zero** console messages, so no CSP violation;
- every refresh rule applied (`document.styleSheets[0].cssRules.length = 126`);
- bar fills resolved to their gradients (`url("#chart-gpu-utilisation-data")`);
- the gauge arc, after its `from`-only keyframe, settled on its attribute value
  (`stroke-dashoffset` 7 = 100 − 93 %);
- `document.getAnimations()` all `finished`.

The spec also asserts that neither stylesheet has an `@import`, a `url(` or an origin, that
the layout imports only `./console.css` and `./refresh.css`, and that the production policy
names no origin and no `unsafe-` source.

## 3. Accessibility

`apps/admin-web/e2e/accessibility.spec.ts` (new, 33 tests) covers five areas.

- **axe-core 4.13.0 in jsdom.** It runs WCAG 2.0/2.1 A and AA plus best practice over
  overview, overview-stale, ops, ops-unconfigured, CI/CD, voice, access and a refused
  state, each in `tr` and `en`. Every page has **0 violations**, and no `style=` reaches
  the markup.
  - **Near-miss:** a nameless `role="img"` is caught as `role-img-alt`, so the harness can
    fail.
  - jsdom has no layout, so axe's `color-contrast` rule is off there and the next point
    replaces it.
- **Contrast, computed from the stylesheet's own tokens in both themes.**
  - Text (`--ink`, `--muted`, the four state colours) is ≥ 4.5:1 on `--surface`, `--bg` and
    `--row-hover`, and so is the navigation on its rail.
  - A state pill's text is ≥ 4.5:1 on its own 10 % tint.
  - Every bar is ≥ 3:1 on its track (WCAG 1.4.11), measured at its faintest gradient end.
  - The focus ring is ≥ 3:1.
  - **Near-miss:** a gradient faded to 0.55 fails the 3:1 floor. That was the first draft's
    value.
- **Motion.**
  - The reduced-motion block removes `animation` and `transition` on `*`, `::before` and
    `::after`.
  - The only `infinite` rule is `.badge[data-state="blocked"]::before`.
  - Every one-shot animation is under 1 s, with `var(--duration-*)` resolved.
- **Text as written.** There is no `text-transform`, no `text-overflow: ellipsis` and no
  `word-break: break-all`.
  - **Near-miss:** a planted uppercase rule is caught.
- **390 px.** In Chrome device emulation at 390 × 844, under the CSP server, every page
  (overview, ops, CI/CD, voice, access) has `scrollWidth == innerWidth == 390`. No element
  outside a table's own scroll container overflows the viewport. Before the fact-list rule,
  CI/CD's deploy gate and error budget pushed the layout viewport to 404 px. This is a
  pre-existing overflow, visible on main's desktop capture too.

`src/ui/charts.test.tsx` (new, 15 tests) covers the following, each with its near-miss:

- figure parsing;
- a share only when the units agree;
- a mark only for a known, non-zero figure (0 prints and draws no bar; unknown prints
  "Unknown");
- a minimum visible width for a tiny figure;
- stale readings hatched and named;
- one gradient per tone per chart;
- safe, distinct element ids;
- the gauge's sweep;
- no `style` attribute.
