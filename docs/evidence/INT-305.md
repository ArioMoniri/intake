## The direction chosen, and why

files/02 §5.4 calls the prompt **one-tap** — "a one-tap *Bu görüşme nasıldı?*
(1–5) … never blocks sending" — and `csat.v1` **required** `reason`, so a single
tap could not form a valid event. Two subsystems disagreed with each other; the
score-only tap fell into the gap.

Resolved in favour of the spec's one-tap intent: **`reason` becomes optional in
`csat.v1`**, and files/02 §5.4 is amended in the same PR to record that a single
tap is itself a complete rating and that no reason is ever defaulted. The
"stop calling it one-tap" direction was rejected because one-tap-never-blocks is
load-bearing in three places in files/02 (§5.4, and the §1/§7 lines
"one-tap CSAT never blocks") — narrowing the field is the smaller, truer change.

An absent reason is honoured as absence, never fabricated:

- **API** (`services/api/src/intake_api/satisfaction.py`): `CsatIn.reason`
  defaults to `None`; the route passes it straight through, so an omitted reason
  reaches the event as `reason: null` — not a guessed enum member.
- **Mobile** (`apps/mobile/src/lib/intake/csat.ts`): `csatResponse` forms a body
  the instant a score is present, and adds the `reason` key **only** when a chip
  was tapped. One tap → `{ score }` with no reason key at all; a chip with no
  score is still `null` (a chip is not a rating).
- **Rollups** (`services/metrics/src/intake_metrics/rollups.py`): `CsatPoint.reason`
  is now `CsatReason | None`; the one-tap score joins the score distribution and
  the mean like any other rating, but `reason_counts` counts only non-`None`
  reasons — a `None` bucket would be a fabricated category indistinguishable from
  a real one (invariant 6), and it would also crash the `csat_reason` label,
  which the projection now never reaches.

All-or-nothing (third acceptance bullet) is structural: the API writes the
`csat.v1` event row or returns an error; there is no partial state, and the
one-tap path adds no `csat_texts` row (it has no text). On mobile the reducer
holds a tap for the patient to enrich, but only `csatResponse` — which returns a
whole body or `null` — is submittable.

Generated artefacts (`schemas/events/csat.v1.json`, `schemas/openapi.json`,
`src/generated/models.ts`) were regenerated with `make schemas-codegen`; `reason`
drops out of `required` and becomes `CsatReason | null` (default `null`),
mirroring how `text` was already optional. The byte-drift test
(`tests/schemas/test_roundtrip.py`) and the TS `generated.test.ts`/`index.test.ts`
stay green.
