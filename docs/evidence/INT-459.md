## Request

On 3 Oct 2026 the owner asked for the admin console to feel premium and Apple-native rather
than AI-generated: the dashboard, the navigation and shell, tables, the Model lanes page,
settings, and the empty, loading and error states. Acceptance, verbatim from the row:

- "Translucent glass only on chrome (sidebar, top bar, sheets); content sits on solid fills;
  prefers-reduced-transparency, prefers-contrast and prefers-reduced-motion each have a
  fallback."
- "Light and dark themes come from one token set, and WCAG AA contrast is asserted by tests in
  both themes."
- "Motion is subtle and spring-based, and none of it is on a critical control."
- "Behaviour is unchanged: no API contract, auth, approval-flow or four-eyes change; no IP
  restriction; no PHI in fixtures."
- "Before/after captures from the local dev server are recorded."

**Reuse check.** Open work was searched first (`gh issue list`, `gh pr list`). INT-450
(#763, PR #776, open and mergeable) already licence-checked the owner's libraries and added
charts and a refresh layer, so this issue is stacked on it rather than competing with it.
INT-428 (PR #751, open, conflicting with main) owns the `/model-lanes` page; INT-434 (#742)

## 2. Change

**Tokens: `app/native-tokens.css`.** One set of names, with a value per theme from
`prefers-color-scheme`:

- system fonts (SF Pro, SF Pro Rounded for gauge figures, SF Mono);
- Apple-like neutrals, tuned until every pair passes AA (§3);
- the radius and spacing scale and the glass recipe;
- two springs.

The sheet redefines every token that `console.css` and `refresh.css` set per theme, so neither
earlier value leaks through.

**Springs.** Each spring is the step response of a damped spring, sampled at 25 points into a
CSS `linear()` curve. The curve is computed, not copied.

- **smooth:** ζ = 1, ω = 9.2 (critically damped, no overshoot).
- **snappy:** ζ = 0.82, ω = 8.2 (peaks at 1.011).

The formulas are x(t) = 1 − e^(−ωt)(1 + ωt) for ζ = 1, and
x(t) = 1 − e^(−ζωt)(cos ω_d t + (ζω/ω_d) sin ω_d t) otherwise, with ω_d = ω√(1 − ζ²).

**Shell: `app/native-shell.css` and `src/ops/nav.tsx`.**

- **Sidebar.** `ConsoleNav` keeps its signature, its `aria-current="page"` marking, and every
  href. It now renders:
  - a mark;
  - the pages under three visible group names (İzleme / Hizmetler / Yönetim), each with a
    symbol;
  - a second `nav` with a Türkçe/English switch that keeps the page.

  On a wide screen this is a floating glass sidebar. Under 1024 px the same markup becomes a
  floating glass capsule tab bar at the bottom.
- **Top bar.** The page header is a sticky glass toolbar with the title and subtitle. The
  glass is a `::before` layer, so the bar never becomes the containing block of the fixed
  sidebar inside it.
- **Glass.** It appears only on `.console-nav` and `.page-head::before`. Each turns solid
  under:
  - `prefers-reduced-transparency: reduce`;
  - `prefers-contrast: more`, which also draws an edge;
  - `@supports not (backdrop-filter)`.

**Content: `app/native-content.css`.** Everything here sits on solid fills.

- **Cards.** A hairline and a soft shadow, with no coloured top stripe.
- **Inspector lists.** The term sits left and the value right, with a hairline between terms.
  A term with several values keeps them in the value column. Before, CI/CD's "unmeasured SLOs"
  zig-zagged across both columns.
- **Tables.** Inset tables with rounded row hover.
- **Gauge.** Rounded figures and no glow.
- **Settings.** The four-eyes forms become settings cards:
  - fields in macOS proportions and a native `select`;
  - an accent checkbox;
  - the capsule primary button at the trailing edge.

  They are not animated (§3).
- **States.**
  - A page with no header (refused or unavailable) is a centred state view, with a symbol
    above the reason.
  - An unknown tile is an inset empty state with a "?" symbol. It still shows its word, its
    reason and no figure (invariant 17).
  - Notices and form results carry a symbol.

**Not found: `app/not-found.tsx` and `src/ui/states.tsx`.**

- It is an empty state in tr and en, each marked with its own `lang`, with one link back to
  the overview.
- It is rendered per request (`await connection()`). A prerendered 404 carries no CSP nonce,
  so the policy blocks its scripts (red run 3).

**Loading: built and withdrawn.**

- A route-level `app/loading.tsx` was built: a static skeleton of the shell, announced as busy
  in both languages, with no figure. It was captured on the dev server.
- In the production build the overview then streamed a late chart segment inside
  `<svg aria-hidden="true" style="display:none" id="S:2">`, which the console's CSP
  (`style-src 'self' 'nonce-…'`, no `unsafe-inline`) refuses.
- It was therefore withdrawn. A loading state needs a security decision first (§6).
- `e2e/states.spec.ts` now asserts that no `loading.*` route file exists, and its near-miss
  reproduces the mechanism with React's own streaming renderer.

**INT-450 files touched (stacked branch).**

- `refresh.css` loses five motions that moved a control or a card holding one:
  - the `.tile` shadow transition;
  - the transitions on `input`/`select`/`textarea`, `button` and `tbody tr td`;
  - the tile entrance on forms and on cards holding a button.
- `e2e/accessibility.spec.ts` reads the stylesheet list from `e2e/support/css.ts`, so its
  contrast, motion, text and CSP checks now cover the new sheets too.

**Model lanes (INT-428, PR #751).**

- **Restyled without code here.** The page is not on main. Its markup uses the shared classes
  (`ops`, `page-head`, `band`, `grid`, `tile`, `facts`, `refusal`, `result`, `fieldset`), so
  it takes the whole shell with no code in this PR. The council chair's lane row is included.
- **Captured on a local overlay.** The captures below come from copying #751's files into
  this worktree uncommitted; they were removed afterwards.
- **Joining the sidebar.** When #751 lands, its page joins the sidebar with one entry in each
  of `ConsolePage`, `GROUP_OF` (`services`), `GLYPH_OF` (`chip`, already drawn) and the two
  label tables.

**Behaviour.** The following are untouched:

- No loader, payload, API path, auth, approval or four-eyes code.
- No CSP (`src/ops/csp.ts`) or proxy change.
- No IP rule.
- No fixture change, and no new dependency.

## 3. Tests

**`e2e/native.spec.ts`** (new, 31 tests):

- **Tokens.** Both themes define every required token and every colour, and the layer
  redefines every per-theme token of the earlier sheets.
  - **Near-miss:** a dark block missing `--muted` is caught.
- **Contrast.** In both themes:
  - text (`--ink`, `--muted`, the four states, `--accent`) is ≥ 4.5:1 on `--bg`, `--surface`,
    `--surface-2`, `--row-hover` and `--field`;
  - the accent button's label is ≥ 4.5:1, rest and pressed;
  - chrome text over glass is ≥ 4.5:1, composited at the 86 % tint over every backdrop that
    can scroll beneath it: every surface and data colour, plus a blurred line of text;
  - the solid fallback and the selected row are ≥ 4.5:1;
  - the focus ring is ≥ 3:1 on every surface.
  - **Near-misses:** Apple's own dark systemBlue under white text fails AA (3.65:1), so the
    fill is darker. A 70 % glass fails over the light red.
- **Glass.**
  - The only backdrop filters are on `.console-nav` and `.page-head::before`.
  - Each uses the chrome tint mixed with transparency.
  - No content selector has a translucent fill.
  - Each glass surface turns solid under all three fallbacks.
  - **Near-miss:** a planted glass `.tile` is caught.
- **Motion.**
  - Both springs are `linear()` curves from 0 to 1, with at least 16 stops, overshoot of at
    most 1.05, and smooth is monotone.
  - Every transition and animation in the layer runs on a spring.
  - Every moving rule in **all five** sheets is matched, in jsdom, against the rendered Voice
    and CI/CD pages. None may match a form, anything inside one, a button, input, select or
    textarea, or anything holding one.
  - **Near-miss:** INT-450's `.grid > .tile` entrance matches the four-eyes forms.
- **Text and CSP.** No case transform, ellipsis or break-all (Turkish casing). No `@import`,
  `url(` or origin. The layout imports the five sheets in order.

**`e2e/states.spec.ts`** (new, 10 tests):

- **Loading:** no route-level loading file exists. **Near-miss:** React streams a late SVG
  segment inside `style="display:none"`.
- **Not found:**
  - the route renders the view and calls `connection()`;
  - tr and en are present, with one link;
  - the symbol is decoration;
  - axe is clean.
- **Refused:**
  - the layer centres a header-less page;
  - the refusal markup is unchanged;
  - **near-miss:** an admitted page (with a header) is not centred, checked with jsdom `:has`.
- **Unknown tile:** an inset and a symbol.

**`src/ops/nav.test.tsx`** (new, 15 tests):

- every page appears once, in group order;
- the group names are present in tr and en;
- each list is labelled by its visible group name;
- the current page is marked and not linked, for every page;
- en links carry `?lang=en`;
- each entry has exactly one hidden, unfocusable symbol beside real text;
- there is no `style=`;
- the language switch keeps the page, marks the current language, sets `hrefLang` and `lang`,
  and never links to the language already shown.

**`e2e/accessibility.spec.ts`** (INT-450): axe stays at 0 violations over 16 page states with
the new navigation.

## 6. Blocked and left open

- **Loading state.** The withdrawn route-level `loading.tsx` needs the CSP to admit React's
  `style="display:none"` on streamed SVG segments. The narrowest form would be
  `style-src-attr 'unsafe-hashes' 'sha256-…'` for that one string. That is a CSP change on the
  admin-console row, and CLAUDE.md requires the owner and the security reviewer for it.
  - Until then, the previous page stays up while the next one loads, and the browser shows
    its own progress.
- **Model lanes nav entry.** It is three lines in `src/ops/nav.tsx`, and it belongs to PR #751
  (or to whichever of #751 and this PR merges second).
- **INT-450 coupling.** This branch carries #776's commits until #776 merges. Review the diff
  from `d7e13fc9`.
