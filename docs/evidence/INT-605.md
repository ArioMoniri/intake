## 1. Which cache the host serves from

`make clips` / `intake-clips` (INT-060) writes the MinIO clip cache, keyed by compiled-manifest clip ids. The synthetic host's route does not read that cache. `infra/staging/compose.yaml` sets `INTAKE_HOSTED_TTS=elevenlabs` and `INTAKE_HOSTED_TTS_CACHE_DIR=/var/lib/intake/george-clips`, a persistent volume addressed by `delivery.<context>@v<version>/clip_text_hash(text_tr)`.

`services/api/src/intake_api/george_prebake.py` is the repo's path for filling exactly that cache from the catalogue the route admits, so it is the path used here. The `INTAKE_CLIPS_BUCKET` S3 bucket is reachable (head_bucket and list_objects_v2 succeed) and empty, and nothing on the host reads it, so nothing was written there.
