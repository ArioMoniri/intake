# Evidence — INT-323 · Department-dynamic previsit routing (inbound department → branch → served pack)

## 1. Scope, and what it deliberately is not

Today a received visit's `department` string is regex-matched to ~10 mobile
fixture packs and **silently falls back to `general`**
(`apps/mobile/src/lib/intake/questions.ts` `packForDepartment`). INT-323 builds
the **durable backend** layer that maps a received department (from the
Acıbadem/MHRS connector, or any inbound source) onto the branch taxonomy
(files/09 §1) and resolves the SERVED pack per CLAUDE.md invariant 13 — with the
silent fallback removed: an unmapped department is an EXPLICIT state and the
live path fails closed.

New module: `packages/protocols/src/protocols/department_routing.py`. It sits
one level above INT-042's `resolve_branch`: department → **branch** (new) →
pack (reused).

What it is **not**:

- **not** a new persisted personal-data field. The API opt-in
  `resolve_department` is a request-time routing control (a bool), not a data
  category; the department string (INT-197) and the derived `branch_id`
  (INT-134) are already inventoried, so invariant 18 needs no new annotation.
- **not** a change to the mobile fixture packs — they stay as-is (task scope).
- **not** an invention of pack content or branch ids. Every branch id is a
  `branches.yaml` branch; the served pack CONTENT past L0 remains gated on
  **HB-C1** (clinical sign-off), exactly as INT-042/INT-043 — so the mechanism
  fails closed by construction while that gate is open.
- **not** a fuzzy/substring matcher. Matching is EXACT on the folded key, so a
  partial or unknown department is UNMAPPED rather than routed into a
  neighbouring specialty (the discipline invariant 22 states as "`üre` is never
  substring-matched", applied to routing).

## 2. Alias provenance (derived, not invented)

`DEPARTMENT_ALIASES` is transcribed (already folded) from the committed mobile
`PACKS` regexes in `apps/mobile/src/lib/intake/questions.ts` — the app's own
derived short forms/synonyms — each mapped to the corresponding `branches.yaml`
branch id:

| mobile regex | folded alias(es) | branch id |
|---|---|---|
| `ic hastalik\|dahiliye` | `dahiliye` | `ic_hastaliklari` |
| `kulak\|kbb\|burun bogaz` | `kbb`, `kulak burun bogaz` | `kulak_burun_bogaz_hastaliklari` |
| `ortopedi\|travmatoloji` | `ortopedi`, `travmatoloji` | `ortopedi_ve_travmatoloji` |
| `cilt\|cildiye\|dermatoloji` | `cilt`, `cildiye`, `dermatoloji` | `deri_ve_zuhrevi_hastaliklari` |
| `gogus\|pulmonoloji` | `gogus`, `pulmonoloji` | `gogus_hastaliklari` |
| `kadin dogum\|jinekoloji\|kadin hastaliklari` | `kadin dogum`, `jinekoloji` | `kadin_hastaliklari_ve_dogum` |
| `uroloji\|bevliye` | `bevliye` | `uroloji` |
| `goz` | `goz` | `goz_hastaliklari` |
| `gastro\|mide barsak\|sindirim` | `gastro`, `mide barsak`, `sindirim` | `gastroenteroloji` |

Exact `name_tr` values (e.g. "Kardiyoloji", "İç Hastalıkları", "Nöroloji") are
indexed directly from the taxonomy and need no alias entry. `department_index`
re-checks every alias against the loaded taxonomy at build time and raises
`TaxonomyError` on a stale/colliding alias or an ambiguous folded name — a
fail-closed build guard, not a runtime surprise.

## 3. Fail-closed design (invariant 13)

- **department → branch** (`map_department`) — exact folded-key match; anything
  else is `DepartmentMatch.UNMAPPED` with `branch_id=None`. Never raises, never
  guesses.
- **branch → served pack** (`resolve_department`) — delegates to
  `protocols.taxonomy.resolve_branch`, so: unmapped department →
  `DepartmentNotRoutableError` (no pack); L0-only branch → `L0PackServedError`;
  Acil Tıp → `ExcludedBranchError`; nothing servable → `NoServablePackError`
  (never bare `base.intake`); a mapped branch with an L1+ pack → DIRECT, else
  its cluster pack → CLUSTER.
- **API wiring** (`services/api` INT-197 mirror path) — a new opt-in
  `resolve_department` maps a free-text department onto the branch and threads
  it onto the visit. Default `False` keeps the INT-197 mirror path
  byte-for-byte (proved by `test_default_mirror_path_still_derives_no_branch`
  and the unchanged `tests/api/test_visits.py`). An unmapped department keeps
  its free text and derives no branch; a department mapping to Acil Tıp is
  refused with `excluded_branch`. The branch → pack step stays with the runtime
  (the API loads no packs — same separation as INT-134/INT-042).

## 4. Fold parity with the mobile app

`fold_department` mirrors the mobile `foldDepartment`: locale-independent
lowercase → NFD → strip combining diacritics → `ı`/`İ` → `i`. So
"İç Hastalıkları", "iç hastalıkları" and "ic hastaliklari" fold to one key
(`test_fold_mirrors_the_mobile_normalisation`), and the fold is idempotent.

## 7. What was deliberately NOT done (HB-C1)

Live SERVING of a resolved pack needs L1+ pack content, which is gated on
**HB-C1** (Dr Efe Onganer, physician of record — sign the `clinical_signoff`
block; the compiler refuses an L1 bundle while it is null). Until then every
branch resolves to an L0 draft or nothing, and `resolve_department` raises
`L0PackServedError`/`NoServablePackError` accordingly — the intended fail-closed
state. INT-323 delivers the routing mechanism; it invents no pack content and no
branch id to work around that gate.
