# Evidence — INT-300 · A locale without pinned, licence-verified speech models is text-only, and a locale without a number expander cannot speak a numeral at all

Epic E05-voice · phase P1 · `sec_row: voice-runtime` · depends on INT-296 (done), INT-297 (done).

Two mechanisms, both fail-closed, and **no model added**:

1. **The voice profile is per locale.** A locale whose ASR and TTS are not both pinned in
   the self-hosting registry resolves to `typed` — never to the Turkish voice. Handing a
   non-Turkish session `residency_tr` would speak Turkish audio at a patient who did not
   choose Turkish.
2. **Invariant 22 is per locale.** The compiler's numeral→orthography expansion is Turkish;
   a locale with no expander of its own makes a numeral **unspeakable** (a compile refusal),
   rather than passing a digit to a TTS model whose normaliser would read it wrongly.

`residency_tr` and `typed` remain the only voice profiles (invariant 19). Both new
registries — `LOCALE_VOICE_MODELS` and `LOCALE_EXPANDERS` — gain the per-locale *shape* and
hold exactly `tr`, mirroring INT-296's `LOCALE_REGISTRY`.

## 1. A note on the acceptance's "HB-O6"

`.github/workflows/security.yml` fixes. The sibling INT-296 modules
(`intake_platform/locale/registry.py`, `protocols/locale_text.py`) already cite HB-O5. So
the code follows HB-O5 (accurate, and consistent with its neighbours) rather than propagate
the typo; HB-I10/HB-I11 (the raw-LICENSE-blob work for Turkish's own rows) are cited as
written. No id was minted.

## 4. The two load-bearing refusals

### 4a. A numeral in an expander-less locale is unspeakable

`test_an_expanderless_locale_refuses_a_numeral` plants `"2 mg"` in a locale with no
expander and asserts `NumeralWithoutExpander`. Because that exception subclasses
`TrExpansionError`, `emit_clips` catches it in the handler it already has and turns it into a
`TR_EXPANSION_FAILED` refusal — the compiler refuses to hand the numeral to any TTS model
rather than running the Turkish expander over another language
(`test_the_refusal_is_a_tr_expansion_error_so_the_clip_emitter_catches_it`). The `tr` path is
byte-identical to before: `expand_for_locale("Günde 2 mg", "tr").text == expand_tr("Günde 2 mg").text`.

The refusal is scoped to numerals: numeral-free prose in an expander-less locale is speakable
verbatim (`test_an_expanderless_locale_speaks_numeral_free_text_verbatim`), so a locale is not
silenced wholesale — only its numerals are, until it has its own expander.

### 4b. A locale without both models pinned resolves to typed, never a Turkish voice

`test_an_unregistered_locale_resolves_to_typed_never_a_turkish_voice` asserts both that the
result *is* `typed` and that it is *not* `residency_tr`. `test_a_locale_whose_asr_is_not_registered_types`
exercises the "without both pinned" branch end to end: against a temporary registry that
carries the TTS component but not the ASR one, even `tr` falls back to `typed` rather than
speaking half a voice. `speech_pinned` is the seam: True only when both §4.9.1 rows resolve,
and `ModelStackRow.ASR_PRIMARY` (row 1, served nowhere) proves the False path.

The PHI-serving gate is deliberately **not** restated here: `require_phi_path_pin`
(HB-I10/HB-I11) still decides whether Turkish's registered-but-unverified rows may carry a
real patient's speech. This module decides which profile is *offered*; that gate decides
whether it may *serve*.

## 6. Invariants

- **Invariant 19** — `residency_tr` and `typed` remain the only profiles
  (`test_residency_tr_and_typed_are_the_only_profiles`); the per-locale voice registry holds
  exactly `tr` and adds no model row. A non-Turkish locale never resolves to a Turkish voice.
- **Invariant 22** — the compiler is still the only expander and still runs before the clip
  key is computed; expansion is now per locale, and a locale with no expander refuses a
  numeral rather than emitting one to a TTS model. `tr` output is byte-identical.
- **Invariant 5** — untouched: `tr` remains the source of truth and the default; the two new
  registries are additive and every other locale fails closed (`typed` / unspeakable).
- **Invariant 17** — no placeholder and no invented value: no second-language model row, no
  guessed revision, sha256, WER or expander entry. The registries gain shape and one `tr`
  row each; the rest is left empty (HB-O5, then HB-C19 / HB-I10 / HB-I11).
