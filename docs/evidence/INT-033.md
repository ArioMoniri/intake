## Mapping decisions (blueprint-cited)

- files/03 §4.6 ingestion: `ExtractedRecordItem` ⇄ Observation
  (lab/imaging/procedure via standard observation-category codes) /
  Condition (diagnosis, native `verificationStatus=unconfirmed`) /
  MedicationStatement (status honest `unknown`, INTAKE verification as
  extension) / AllergyIntolerance (native verification). Provenance
  document/page/bbox travels as `urn:intake:` extensions; `unit_conflict`
  travels as a flag extension, never converted (invariant 22).
- files/03 §5: `SessionState` ⇄ QuestionnaireResponse (slots → items;
  list slots marked with a list-slot extension so single-element lists
  survive; None answers are never emitted at any depth — pinned).
  `step_states`/`budget` are engine bookkeeping: the inverse takes them as
  parameters, making the loss explicit in the signature.
- files/03 §7: screening totals → survey Observations with
  `performer=Patient`; the files/04 §4.3 provenance qualifiers ride as
  extensions on every score. C-SSRS never crosses into exchange
  (HUMAN_BLOCKERS.md HB-L2) — pinned by test.
- Invariant 1 interop face: RiskAssessment (method = rules) and Flag
  (RED/YELLOW only) accept `RulesTriageResult` exclusively; an
  `LlmCandidateTriage` raises, the note's `llm_candidates` never appear
  anywhere in the document bundle (sentinel test), and ingestion refuses
  a RiskAssessment whose method is not the rules engine. No probability
  element exists in the RiskAssessment subset at all (invariant 20).
- files/03 §4.8: PreVisitNote → document Bundle (Composition + entries;
  section codes = the files/04 §5 note keys in note order; urn:uuid
  fullUrls, uuid5-deterministic; narrative is escaped XHTML; number+unit
  rendered as one non-breaking atom, no grouping — invariant 22).

not used (not licensed in Türkiye).
