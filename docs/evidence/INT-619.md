Every KIRMIZI rule: `register: ALERT`, `notify_clinic: always`, and an action for all three locations. REMOTE is the CD-24 generic script with 112 written as *yüz on iki* (a chain pack's scripts carry no digit: validator `NUMERAL_IN_TR`, invariant 22). ON_SITE is `GO_TO_IN_HOUSE_ACIL` with no 112 and `notify_staff_immediate: true`, except anaphylaxis, whose ON_SITE is `STAY_IN_PLACE_STAFF_NOTIFIED` because RCUK §4.4 says *"Patients must not walk or stand during acute reactions"*. UNKNOWN asks exactly *"Şu anda hastanede misiniz?"*. The scripts use the bare imperative plural; the probes use `siz` and B1.

Arms deliberately not written, each recorded as a `draft_needs_source` entry in its decision with the invariant-17 literal:

- chest pain: the under-24 h arm (CD-108);
- stroke: the resolved-deficit / TIA action (CD-109);
- anaphylaxis: a patient-facing auto-injector instruction (CD-111);
- bleeding: a volume threshold and melena with dizziness (CD-112);
- sepsis: confusion, low-BP symptoms and rigors (CD-114);
- fever: the adult ≥ 39 °C > 3 d threshold (CD-117, HB-C7).

Adding any of these later is a tightening (invariant 7).

## 2. Slots added (all in `red_flags`, all `must_ask: false`)

Probe copy for `rf_stroke_fast`, `rf_anaphylaxis`, `rf_severe_bleeding`, `rf_sepsis_like`, `rf_thunderclap_headache`, `rf_weight_loss_unintentional`, plus `fever_now`, `age_sixty_or_over` (NG12's bound as a yes/no, never free numeric entry), and the dated anchors `rf_stroke_fast_onset`, `rf_anaphylaxis_onset`, `rf_severe_bleeding_onset`, `fever_onset`, `rf_thunderclap_headache_onset`.

The HB-C6 slot `time_last_known_well` is a duration. The engine cannot anchor on a duration: it reads Unknown, so a rule anchored there never fires. The written stroke rule anchors on its own dated slot. Whether any probe becomes must-ask is HB-C5's fast-mode arithmetic and is not decided here.
