## 2. Diagnosis: why the owner heard "robotic, no emotion, stoppy"

George (ElevenLabs) never spoke a clip, and every miss was silent. Three causes stacked:

1. **401, swallowed.** Since INT-326, `/dev/voice/george-clip` requires an authenticated patient
   (`Principal` + `require_patient`). Mobile `fetchGeorgeClip` posted with no Authorization or
   DPoP header, and `georgePreferringSynth` caught the 401 and fell back.
2. **No base in dev.** In `__DEV__` the API base came only from the LAN :8000 walk (INT-328).
   No API runs on the laptop (owner rule: no Docker or Postgres), so the base was null and the
   source fell back before sending anything.
3. **Not mounted on AWS.** The AWS host runs `INTAKE_ENV=prod*`, and the route is unmounted there.

Every question was therefore spoken by the self-hosted lane (VoxCPM2, else Freya). That lane cut
each question into per-sentence requests (INT-237/291). A question is its title plus an aside,
so the prosody restarted mid-question. Each part was trimmed to 15 ms and the parts were
rejoined with a 200 ms hole. Two more contributors, read in expo-audio 57's iOS module:

- the audio mode was re-applied before every clip;
- every player that finished or paused deactivated the AVAudioSession, under a microphone that
  is open for barge-in.

The pre-warm also fired every clip at once. With George in front, that would overrun the
per-patient budget (30 tokens at 0.5/s, charged on hits too) and the vendor's concurrency. The
overflow would silently drop to the self-hosted voice, giving one visit two voices.

## 3. What changed (client, mobile/voice-client scope)

| Defect | Fix | Test (written red first) |

| Silent fallback | Closed-set `GEORGE_MISSES` (`unauthorized`, `not_mounted`, `rate_limited`, `server_fallback`, …). Each clip records the lane and tier that spoke it. | No API base in dev | The dev resolver falls back to the configured https base when the LAN walk finds nothing, under the release validation. | `apiBase.test.ts` |
| Per-sentence seams ("stoppy") | `shapeForUtterance`: the whole clip is ONE request. Only its outer edges are trimmed, and the turn-yield tail is kept. Invariant 10 and 22 guards are unchanged. | `speechShaping.test.ts`, `tts.test.ts` |

**Setup.**

- Patient: test account Ayşe Yılmaz (synthetic), visit İç Hastalıkları.

**Lane per call.** Every clip played in the run was `elevenlabs-bundled`, `delivery.*@v3`, as

- **ASR latency:** not measured, because no ASR lane was reachable.
- **Next-question latency after a typed answer:** the turn 2–4 figures above. The submit itself advances the turn at once (ask-ahead).
- **Welcome first: yes.** The opening turn plays the welcome, then the orientation line, then the first question, all from the bundle. Screenshot: `screens/INT-440-opening-welcome-bundled-v3.png`. The repair turn is in `screens/INT-440-repair-leadin-bundled-v3.png`.

- **Repair re-ask.** With the extract lane down, typed option answers map to nothing, and INT-293's repair re-ask fires on the next turn. That is the lane outage. It is not judged here.

**Microphone.**

## 6. The clip render (ADR-028)

- The input is `apps/mobile/src/lib/dialogue/bundledClipSet.json` and nothing else. A mobile test holds it equal to the app's own composition over the dev test visits' packs: questions, generic and single-option read-backs, and INT-414's spoken deck lines in their contexts. It is numeral-free and markup-free, with no patient words, RED or instrument lines.
- The renderer re-checks each line's numerals, markup and context, and refuses on any failure.
- The output goes to the gitignored `apps/mobile/assets/clips/<context>/<hash>.wav`. Rendered clips are a dev build input and are never committed: the ElevenLabs vendor terms are an open human blocker (ADR-028 consequences).
- **Spend.** v1 routine-only: 13,132 characters (≈ 3.94 USD estimated). v3: 16,060 characters (≈ 4.82 USD estimated). These are estimates at the 0.30 USD per 1k high-end planning rate; the coordinator ran both. Removing the open-ask tail re-renders 34 lines, 1,109 characters (≈ 0.33 USD).
- **The one line** (from the repository root; it sources the secrets itself, and the tool never prints the key):

  ```sh
  set -a && . ~/.intake-secrets.env && set +a && EVAL_BUDGET_USD=10 uv run python scripts/voice/render_bundled_clips.py --live
  ```
