## Notes and deviations

- files/protocols/base.life_threat.yaml records two open naming conflicts
  (`gate:` vs `when:`, `evidence:` vs `source:`). For chain packs this DSL
  uses `when`/`source` (files/03 §6; files/12 §2.4-2.5 — the names the CI
  gates cite); the life_threat_set document keeps its own names and is
  deliberately NOT loadable as a pack here (INT-041's compiler owns it).
- Digits are rejected in ALL patient-facing tr fields, including RED
  action_tr. "112" therefore cannot be written as digits in a pack; the
  skeleton's own exemplar 4 pattern (action_tr_ref into
  docs/legal/strings.yaml, PolicyGuard-owned) is supported for exactly that
  case, and the compiler's Turkish-orthography expansion (files/03 §4.9.6)
  is INT-041 scope.
- `register` is accepted on non-RED rules (files/protocols/
  base.life_threat.yaml exemplar 2 is SARI_K1 with register CALM) but
  required only on KIRMIZI, matching invariant 21's RED scope.
