## Detail, one check per property

- [x] **A rendered page.** `apps/admin-web` gains the minimal Next.js App Router shell files/08 §7
  names (`app/layout.tsx`, `app/page.tsx` → `/ops`, `app/ops/page.tsx`, `app/healthz/route.ts`,
  `proxy.ts`, one bundled stylesheet). `/ops` is a server component: it forwards the caller's
  bearer to `GET /admin/ops`, then reads `/healthz`, `/readyz`, `/version` of the configured
  `INTAKE_ADMIN_API_BASE`, and renders `src/ops/console.tsx`. `next build` compiles it
  (`/ops` and `/healthz` dynamic, the proxy active); it was driven end to end on this host (see
  *Rendered*).
- [x] **Admission fails closed (HB-A16).** There is one gate, the API's INT-180 one — OIDC
  verifier (503 for everyone while issuer/audience/JWKS mirror are unset), the files/08 §2.3 IP
  allow-list (ships empty, admits nobody), the platform-scope role set, and the audit wrapper. The
  page adds only the two preconditions for asking it: no configured API base → nothing is dialled
  (`api_base_unconfigured`); no well-formed `Bearer` → nothing is dialled (`no_credentials`). A
  401/403/503 renders the refusal (`token_refused` / `role_not_permitted` / `source_ip_refused` /
  `console_unconfigured`) and **no further call is made**, so a refused caller does not learn the
  API's health either. `GET /admin/ops` is a new `ADMIN_ROUTES` descriptor (`admin.ops.read`,
  platform-scope roles), audited like every other route; `tests/admin/test_rbac_matrix.py` and
  `test_admin_audit.py` derive it from the served route table.
- [x] **Every tile has a real source and fails closed to `unknown`.**

  | Tile | Source (server-side only) |
  |---|---|
  | API health | `/healthz`, `/readyz`, `/version` (`git_sha`, `built_at`) of `INTAKE_ADMIN_API_BASE`, the shared `intake_platform.health` contract |

  | Model usage | `work_latency_ms` (count, p95), `work_failed_total` by work type; `voice_tts_chars` count by vendor; `vendor_adapter_failures_total` by adapter — 24 h |
  | ElevenLabs scripted-clip cache (manifest & usage) | usage: `voice_clip_cache_lookups_total{outcome}` (hit = reused, miss = synthesised) and `voice_clip_syntheses_total{gateway,outcome}` (gateway `elevenlabs` / `self_hosted` / `recorded`); manifest: `voice_clip_manifest_rows` / `voice_clip_manifest_present{pack,locale,voice}` — all new, set by the ADR-028 clip build (`voice_clips.metrics`), written as a textfile and re-exported by the collector |

  Prometheus is read by `services/api/src/intake_api/admin/ops_prom.py` from
  `INTAKE_OPS_PROMETHEUS_URL` with a fixed query table (`OPS_QUERIES`) — a request field never
  reaches a query (files/08 §0b F1). Unset → every Prometheus tile is `unknown` /

  collector source (`collector_source_failing`) each yield their own reason. One failing query

- [x] **GPU quota / host status from a collector that runs server-side with its own access.**
  `services/probes/src/intake_probes/ops_collector.py` (+ `ops_gpu.py`, `ops_ci.py`) runs as a
  background loop inside the probes service when `INTAKE_OPS_GPU_HOST_ID`,

- [x] **No PHI on any tile (invariant 6).** Server side, a series whose label set differs from

  half-painted page.

## Design notes

- **Why the API composes and the page only renders.** files/08 §0b F1: every panel is
  server-rendered through `services/api/admin`, and the API is where the audit wrapper, the role
  matrix and the OpenBao client already live. The API never dials GitHub or a GPU host — it sits
  on the PHI network, which has no egress; it reads Prometheus (internal observability) and the
  registry. External facts arrive as series from the collector.
- **The CI read uses the existing `api.github.com` allow-list row** (`issue_tracking`: repository
  metadata, the same client class as `gh`). A distinct `ci_status` purpose would be an ADR-025
  change to `infra/security/egress-allowlist.yaml`, a hook-protected tier-2 file; not made here.
- **EC2 vCPU service quota is not collected.** It needs an AWS endpoint that is not on the egress
  allow-list; "quota" on the tile is the GPU memory the host (MIG slice / pod) is allotted, as
  `nvidia-smi` reports it. Adding the AWS quota is an allow-list decision for the owner.
- **Clip cache = the offline build's cache.** The ADR-028 build is where a hit (clip reused, no
  vendor call) and a miss (synthesis) happen; the runtime Talker plays pre-built clips. The build
  is a batch job, so its counters live on their own registry, are written as a textfile when
  `INTAKE_CLIPS_METRICS_TEXTFILE` is set, and the collector re-exports only those two families.
- **Supply chain.** New npm dependencies: `next@16.3.6`, `react@19.2.3`, `react-dom@19.2.3`
  (already in the lock for mobile), `@types/react@19.2.18`, `@types/react-dom@19.2.7`. Licence
  blobs read from the installed packages: `next/license.md` MIT (Vercel), `react/LICENSE` and
  `react-dom/LICENSE` MIT (Meta). `sharp` (Next's optional image dependency, whose
  `@img/sharp-libvips-*` binary is LGPL-3.0-or-later and failed `check_licenses.py`) is excluded
  with `pnpm.ignoredOptionalDependencies: ["sharp"]` and the console sets
  `images.unoptimized`. `osv-scanner -L pnpm-lock.yaml`: no issues. `check_licenses.py`: OK.
- **CSP** (`src/ops/csp.ts`, `proxy.ts`): per-request nonce, `strict-dynamic`, no `unsafe-*`
  outside `next dev`, `frame-src 'none'`, `frame-ancestors 'none'`, `base-uri 'none'`,
  `object-src 'none'`; plus `no-referrer`, `nosniff`, `X-Frame-Options: DENY`, `no-store`. No
  `style` attribute is used anywhere (the policy has no `unsafe-inline`). Observed on the running
  build: the header is emitted, the stylesheet loads and the console logs no CSP violation.

`e2e/ops.spec.ts` drives the page's own loader through an injected `fetch` answering from
recorded responses (tests only) and renders the page's own React tree to static markup. The
recorded responses are produced by `scripts/dev/record_ops_fixture.py` (`make admin-fixtures`):
the real composite over the real registry and the recorded Prometheus answers, the real
composite with no Prometheus, and the real `mount_health` contract stamped with this checkout's
HEAD. The Prometheus answers (`tests/fixtures/ops/prometheus_responses.json`) are constructed in
the documented HTTP API shape — no Prometheus runs on this host; the GitHub Actions answer
(`tests/fixtures/ops/github_actions_runs_main.json`) was recorded from the live API on
2026-09-26 and reduced to the fields the collector reads (no actor, no commit message).

Near-miss controls, each paired with its positive: a missing/refused/unauthorised/unconfigured
caller sees no tile and triggers no health call; a stale GPU reading does not survive a failed
query; a failed CI read clears the old runs; a CI series with a failing collector reads unknown;
an unknown tile carrying a figure is refused; a lane or workflow label with a name in it is
refused; a CSAT or wait mean below k = 10 is refused (and one flagged not-suppressed is still
refused); a `target` key is refused; a clip textfile holding a smuggled family re-exports only
the clip families; the CSP carries no `unsafe-*` in production and refuses a non-base64 nonce.
