## Acceptance (verbatim from docs/backlog/issues.yaml), and where each lands

- [x] **"in-process on the agent worker, no network capability at type level
  (inv. 13); one audio stream (inv. 12)"** — `SERModel` is a `Protocol` with two
  members only, `{infer, model_ref}`: no client, no URL, no stream handle, so the
  type cannot express a second capture. `infer` is handed the window's own PCM
  frames and the window's own sampling rate. The module imports no transport
  library (AST test), and INT-110's package-wide gate
  (`test_no_observer_module_can_open_an_audio_transport`) still holds.
- [x] **"output drives only pace, break_offer and confirm_by_card inside M1;
  nothing but the closed InteractionState crosses the M1 boundary (inv. 22)"** —
  `AffectInference` has fields for exactly those three (plus `confidence`) and
  **none** for `modality`, `repeat_request` or `third_party_present`, so the
  model cannot express a change to them. `reduce_interaction` sets only the three
  and copies the other three through untouched; a parametrised test asserts they
  never move. Through the runtime, an admitted affect lane writes **nothing** to
  `ObserverState` — its numeric read dies in the M1 store (`M1_INTERNAL`,
  INT-110). The lane's egress is a closed `InteractionState`.
- [x] **"confidence>=0.6; per-section aggregate only; never an accent
  judgement"** — `AFFECT_CONFIDENCE_GATE == 0.6`; a window below it contributes
  nothing and drives no interaction change; a section whose windows all fall
  below the gate yields no observation. The lane aggregates per section (keys are
  `"<section>.samples"` / `"<section>.contributing"`); the interaction reflects
  the section aggregate, not a single window. "never an accent judgement" is
  structural: neither `AffectInference` nor any marker key has a field or token
  for an accent, a dialect, a language, an origin or an identity.
- [~] **"a held-out Turkish clinical eval set is a REQUIRED deliverable and is
  checked in before the lane is enabled by default …"** — the **gate** is built
  and fails closed; the **content** is HB-C11. `admit_affect` refuses every model
  whose weights have no evaluation recorded in `affect_enablement.yaml`, which
  ships empty, and `AffectLane` cannot be built without the `AffectAdmission`
  that gate mints. A synthetic evaluation opens the gate in the test, so it is a
  real check and not a permanent refusal (the acoustic-study-gate shape reused).
  No SER model, corpus or affect figure is invented (files/00 §5 Q5).
- [~] **"no accuracy claim leaves docs/evidence/; the eval report is dated and
  names its corpus"** — the enablement record carries **no result number**: its
  fields are `{model_ref, corpus, evaluated_on, sign_off}` and a test asserts no
  `accuracy`/`ua`/`auroc`/… field and no performance figure (a number beside a
  claim word, or a percentage) in the module or the registry. When the eval
  exists it is dated and names its corpus, in `docs/evidence/`, per invariant 20.

`[~]` = the mechanism is delivered and fails closed; the clinical content the
clause also asks for is `awaiting-human` (HB-C11).

## What this issue is, and what it deliberately is not

**No SER model is wired, and none can be today.** Row 14's weights are
licence-clean — `ASLP-lab/Emotion2Vec-S` (Apache-2.0), or an ordinal head on
`microsoft/wavlm-large` / `facebook/wav2vec2-xls-r-300m` — but **no open SER
model has a published Turkish evaluation** (files/03 §4.7.1, files/00 §5 Q5).
`SERModel` is therefore a *port* with **no implementation**; nothing is bundled
and nothing scores audio, exactly as `acoustic`'s ordinal head is a seam without
a body. `emotion2vec+` is **not** used (disqualified on licence, §4.9.2(c)).

**No clinical content and no number were authored.** No affect threshold beyond
the blueprint-pinned 0.6 confidence gate (§4.5b/§4.8, a decision boundary, not a
measurement); no corpus; no accuracy, UA or AUROC figure anywhere. The test
double (`ScriptedSER`) returns caller-scripted inferences and scores nothing —
inventing an affect read would be inventing the artefact HB-C11 says does not
exist. Every Turkish string is synthetic (files/04 §7).

**INT-110 is untouched.** The lane framework, its five isolation locks and the
fake-clock latency proof are unchanged; the affect lane admitted on consent alone
still routes to the M1 no-op store. INT-111 adds the model + eval gate at the
*construction* layer (a lane cannot be built without a bound model and an
admission) and the M1 interaction reducer, without changing `admit`.

## The fail-closed gate, in one paragraph

`build_affect_lane` resolves `admit_affect(model.model_ref, registry=…)` before
constructing anything. The registry defaults to the shipped
`affect_enablement.yaml`, which holds `evaluations: []`, so `admit_affect` raises
`AffectEvalUnavailableError` and no lane is built — for any model, real or test.
An evaluation vouches for the exact `model_id@revision` it was run against, so
even a bound model whose weights have an eval for a *different* ref is refused.
Filling one row needs a checked-in Turkish clinical evaluation and a clinician
sign-off (`model_ref`, `corpus`, `evaluated_on`, `sign_off` — never a number),
which is HB-C11 and `approval:human-clinical`. Until then the lane is disabled by
default and the mechanism sits behind the gate, unreachable, not merely
unrendered.
