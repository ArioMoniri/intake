# Evidence — INT-310 · Eight npm advisories cleared by upgrading, not by suppression

Date: 2026-09-03. Branch `int-310-dep-bump`, off `origin/main` at `11c9fe4`.

## What was wrong

INT-019 built the twelve-step security gate set and **refused to suppress**
what step 6 found. That refusal is why `make security` is honestly red rather
than falsely green, and it is the whole reason this issue exists: the eight
advisories are real, and the fix is a major-version bump across the pnpm
workspace, which is its own change with its own blast radius.

Six packages, eight advisories, one ecosystem (npm). None of them is a
first-party declaration: `vitest` is the only one this repo names directly, and
the other five arrive transitively through it, through `expo-router` and
through the Expo build tooling.
