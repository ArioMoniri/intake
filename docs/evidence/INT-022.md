## Decisions surfaced while proving it

- **"Enabled" = `self_hosted_now: true`.** The acceptance says "enabled
  phi_path component" but the nine-key schema has no `enabled` field; a
  planned row (voice-runtime, api, freya-tts, edge-tls) binds the moment it
  runs, never before.
- **Fallback is typed**: `none` | `component:<name>` (resolved in-registry,
  must be self-hosted and probe-healthy) | `in-process:<module>` (ships
  inside the component's own artefact — as alive as the component itself).
- **`api` is in the registry but not running**: the brief groups it with the
  running components, yet no `services/api` exists on this base — the row is
  honest (`self_hosted_now: false`, E02 tier cited) rather than aspirational.
- **redis is `phi_path: false` today** — it holds rate-limit counters and
  idempotency keys over tokenized principals only (INT-176/177); the row
  comment flips it to true the moment session/clinical state lands there.
- **cert expiry** got its component (`edge-tls`, planned): the dev tier is
  loopback plaintext, so the probe targets `INTAKE_TLS_PROBE_TARGET` when an
  edge terminator exists; the ssl fetch itself is tested against a local
  self-signed server.
- **Coverage floor**: `scripts/ci/coverage_thresholds.yaml` is hook-protected
  and check-py's `--cov` currently measures `packages/intake_platform` only;
  the probes package's measured 99 % is recorded here, and wiring its floor
  into check-py belongs to the issue that next touches that gate.
