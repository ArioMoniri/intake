# INT-486 — ops_prom label check uses fullmatch, so a trailing newline is refused

GitHub #831 · Sec-Row `admin-console` · phase P1 · 4 Oct 2026

**Acceptance, verbatim from `docs/backlog/issues.yaml`:**
- "every label-shape check in services/api/src/intake_api/admin/ (ops_prom.PromSession) uses fullmatch, so a label value with a trailing newline is not id-shaped" — **met.** See the fix below.
- "a near-miss test in tests/admin/test_ops_console.py: an id label 'api\n' and a ref label 'main\n' turn their tile unknown with label_not_id_shaped, while 'api' and 'main' are painted" — **met.** See Tests, and the red and green runs.

**The defect.** `PromSession.fetch` (`services/api/src/intake_api/admin/ops_prom.py`)
feeds the ops, reliability, CI/CD and voice admin consoles. It held every
Prometheus label value to `ID_LABEL` or `BRANCH_LABEL` with `re.match`. Both
patterns end in `$`, and Python's `$` also matches just before a final `"\n"`.
So `ID_LABEL.match("api\n")` matched, and a value with a trailing newline was
painted on the console. It should have turned the tile `unknown` with
`label_not_id_shaped` (invariant 6: label values reaching the console are
id-shaped).

**The fix.** `pattern.fullmatch(value)`. The whole value is held to the shape,
and the patterns themselves are unchanged. This is the same check `cicd_console`
already makes with `ID_LABEL.fullmatch`. A grep of
`services/api/src/intake_api/admin/` finds no other `.match(` call.

The mirror assertion in `tests/observability/test_ops_cicd.py` checks that the
collector's exported labels have the API's PromSession shapes. It also used
`.match`, and now uses `.fullmatch`, so it holds the same contract.

**Out of scope.** The probe emitters (`services/probes/src/intake_probes/ops_ci.py`,
`ops_cicd.py`, `ops_gpu.py`) make the same `$` + `.match` check on the emitting
side. They are INT-487 (#832). The API-side check fixed here is the one that
decides what a console paints, so it holds whatever an emitter sends.

## Tests

`tests/admin/test_ops_console.py::TestPhiAndFloor` has two tests. Each pairs a
clean value (the near-miss control) with the same value plus `"\n"`:

| Test | Label (pattern) | Clean value: painted | Value + `"\n"`: unknown |
|---|---|---|---|
| `test_an_id_label_with_a_trailing_newline_is_not_id_shaped` | `adapter` (`ID_LABEL`) | `"api"`, a `model_usage` lane | `"api\n"`, `label_not_id_shaped`, no lanes |
| `test_a_ref_label_with_a_trailing_newline_is_not_ref_shaped` | `branch` (`BRANCH_LABEL`) | `"main"`, the `cicd` branch | `"main\n"`, `label_not_id_shaped`, no branch or workflows |
