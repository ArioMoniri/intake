### What keeps a citation from being theatre

A consolidation that re-imports and re-asserts other suites' logic proves nothing. Every
citation in `INVARIANTS` is checked three ways, per node id (74 nodes × 3 = 222 of the 311
tests):

- `test_every_cited_test_exists_in_its_module` — AST-parses the cited file and requires the
  function (or `Class::method`) to be defined.
- `test_no_cited_test_is_skipped_or_xfailed` — a cited test carrying `skip`/`xfail` is a
  citation to something that does not run (CLAUDE.md invariant 17).
- `test_every_cited_test_is_still_collected_by_pytest` — runs `pytest --collect-only` over
  the cited files in a subprocess and matches each node id as a prefix, so a module that
  stops importing, or a test that is deselected, fails **here**.

The clauses themselves are re-read out of `CLAUDE.md` at test time
(`test_every_clause_is_quoted_verbatim_from_claude_md`), so the ledger cannot drift from
the constitution, and `test_a_doctored_clause_is_not_found_in_claude_md` is the control.

### The genuinely new ones, in one sentence each

- **inv 1** — nothing under `services/voice-runtime/src` *constructs* a triage
  determination (`RulesTriageResult`, `TriageEvaluation`, `evaluate_triage`,
  `with_candidates`, `RuleFire`). Reading a level stays permitted; producing one does not
  exist in the runtime.
- **inv 2** — every function in the runtime that reaches `speak` / `synthesize` / `play`
  also calls `PolicyGuard.filter`, with exactly two named grants (`SpeechRouter.speak`,
  whose callers guard; `_speak_bridge`, which plays a signed-off clip id and has no
  sentence to inspect). The grant list may only shrink and each grant must still be
  load-bearing. Behaviourally, a Layer-B diagnosis sentence reaches neither the synthesiser
  nor the sink.
- **inv 3** — a turn that cancels playback and fires a RED (the newest audio-adjacent path
  in the runtime, INT-093, postdating the simulator's probe) opens no write-mode file and
  leaves the session holding zero bytes-like attributes.
- **inv 4** — the runtime names no store and no share API: `sqlalchemy`, `psycopg`,
  `boto3`, `minio`, `redis`, `httpx`, `requests`, `intake_api`, and the `intake_platform`
  `db`/`audit`/`access_log`/`documents`/`uploads`/`consent`/`retention`/`research` modules
  are all absent from its import graph, so Layer A has no path by which an unconsented read
  or an unaudited share could happen at all.
- **inv 5** — no string literal is passed as the text argument to the speech router, the
  synthesiser or PolicyGuard anywhere in the runtime: everything spoken came from the
  compiled pack (`text_tr`) or Layer B.
- **inv 6** — no log-emitting call in the runtime carries a non-id argument (there are
  currently zero such call sites, so this is a live ratchet), and every metric label is an
  enum member's `.value` or a closed name.
- **inv 8** — a floor one point below the invariant is caught. `tests/ci/test_coverage_floors.py`
  asserts the floors are met but has no control proving the predicate can fail.
- **inv 9** — the four clauses **together**, in one session with a stalled backend, a
  waiting YELLOW and a firing RED. Each clause has its own suite; nothing held them at once,
  and ordering bugs (a RED after the insertion tick, a YELLOW jumping the queue because a
  RED was pending) live exactly in that gap. A second new test asserts the **sequence**
  rather than two counters: with the window open, one turn's log must read

- **inv 10** — all five `StepKind`s, and the AST gate that `NextStep` is only ever built
  through `NextStep.of`. The type permits `kind=SCRIPTED, allow_paraphrase=True`, which

  and nothing asserted that before.
- **inv 11** — `must_ask_invariance` (files/03 §4.6 invariant 21), which
  `docs/evidence/INT-110.md` explicitly handed to this issue: the real `ObserverScheduler`

## 7. The harness — and what it does not measure

`tests/voice/latency_harness.py` drives a **real** intake: the production compiler's
resolved pack, the real `IntakeEngine`, the real `TalkerSession` / `TypedSession`, the real
`ObserverScheduler`. `services/voice-runtime/src/intake_voice_runtime/budgets.py` holds the
budget table and the report type.

**Everything is fake-clock.** No test in this issue reads a wall clock. INT-091's
`FakeClock` advances only when every task is parked, as INT-093 used it. A wall-clock
latency assertion in CI is a flake and INT-264 is what that costs.

### What the harness measures

Virtual milliseconds charged to the session clock per turn, split into
`modelled_playback_ms` — the part the harness itself puts there, at a declared
`_PLAYBACK_MS_PER_BYTE` — and the remainder, `orchestration_ms`: every await the runtime
performs that is **not** playback. That remainder is the number worth reporting, and it is
`0.0` on every turn of every profile. A stalled Backend Agent (10 s, 30 s, 40 s), a stalled
observer lane (30 s) and two background Work items change none of it.

**The zero is a measurement, not a constant.** `test_the_orchestration_meter_reads_zero_and_can_still_move`
runs the same harness with a sink that sleeps 7 ms outside the declared playback model and
asserts the meter reads exactly `7.0` — a meter that cannot move proves nothing.

### What the harness does NOT measure

**There is no GPU and no model in this container.** Not one number here is a model latency,
and the report says so in a field (`does_not_measure`) rather than in a comment:

- **ASR / speech-to-text** — no model, no GPU.
- **LLM time to first token** — the Talker holds no model; dynamic text arrives as a string
  from Layer B.
- **TTS first byte** — the synthesiser is a recorded double returning opaque bytes.
- **Network transport, jitter buffer, device output** — no media transport exists here.
- **PolicyGuard wall time** — the guard reports its own `perf_counter` figure; this harness
  reads it from no report and asserts it nowhere.

files/02 §8.1 fixes the measurement point once: *"last patient speech sample → first agent
audio sample, on device, client clock."* **The harness does not measure that**, so
`TurnBudgetReport.verdict()` **raises `NotALatencyMeasurement`** rather than returning a
pass/fail. A method that quietly returned one would manufacture a performance claim out of
a harness artefact (CLAUDE.md invariant 20).

cell is unset **for a stated reason**, and `TurnBudget` refuses to be constructed with
neither a number nor a reason, or with a reason of `AWAITING_MEASUREMENT` and no blocker id.
Each row's `blueprint_quote` is re-read out of files/02 at test time.

| `residency_tr` | dynamic | p95 | *unset* — `awaiting_measurement`, **HB-C10** | `**OPEN — to be measured** \| Deliberately unset.` |
