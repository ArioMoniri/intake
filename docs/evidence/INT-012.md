## What the tests pin

- **Headers** — CSP `default-src 'none'; frame-ancestors 'none'`, HSTS
  (2-year max-age, subdomains), nosniff, frame-deny on every response
  (pure-ASGI middleware; existing headers are never clobbered).
- **Token bucket** — atomic Lua script in Redis (read-modify-write under
  concurrency is where Python-side limiters silently over-admit): allows to
  capacity then refuses with a retry-after estimate; refills by elapsed time;
  capacity is a ceiling, not a starting credit (an hour of refill still caps);
  user/ip/tenant dimensions and identifiers are isolated buckets; unknown
  dimension is a ValueError. Clock injected — deterministic tests, no
  wall-clock flake (docs/TDD.md rule 6). fakeredis[lua] in tests.
- **Idempotency** — POST + `Idempotency-Key`: duplicate with same body replays
  the stored response (`Idempotency-Replayed: true`, handler runs once); same
  key + different body → 422 (client bug, not a replay); concurrent duplicate
  while in flight → 409; POST without the key passes through; GET untouched;
  a raising handler releases the key so the first attempt stays retryable
  (asserted implicitly by the 5xx/exception release path).
