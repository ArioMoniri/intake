## The NER model — trained by us, provenance in hand (the D14 philosophy)

Every off-the-shelf Turkish NER candidate failed the C2 licence gate — the
most-downloaded one (74.8k) carries an MIT *tag* with **no LICENSE blob** and
unversioned training data. So the tier is our own fine-tune:

- **Base**: `dbmdz/distilbert-base-turkish-cased` — MIT verified from the raw
  LICENSE blob of the source repo (github.com/dbmdz/berts, Bayerische
  Staatsbibliothek); hub revision at training time b6e1de16 (future retrains
  pin the revision in the script — noted as an improvement).
- **Data**: `BTX24/turkish-privacy-pii-ner` @ 45a8e18 — **CC-BY-4.0**,
  machine-generated synthetic (no real persons), 103,923 rows, 10 classes.
- **Run**: team H200, /data/intake (guarded — resource floors held), seed 42,
  2 epochs, bf16; script `train_ner.py` records everything in
  `provenance.json`; `SHA256SUMS` covers every artefact file; the pickle
  `training_args.bin` was stripped from the distribution.
- **Measured** (dated internal measurement, D16 — not a claim): token-level
  test recall ≥ 0.9994 on all 10 classes (synthetic held-out; the honest
  caveat is that machine-generated text is easy — the Turkish clinical
  eval set remains HB-C10, unchanged).
- **Distribution**: repo release `deid-tr-ner-v1` (tarball sha256
  d4faec572e37f81697fa25500230acc060fd8517443e226227a2b11630f5bcb9);
  `make deid-model` fetches via `gh` (no vendor), verifies the pinned sha,
  extracts to .cache/; CI caches it (actions/cache pinned by commit SHA).
  Tests REQUIRE the model — absence fails with the fetch instruction, never
  skips.

## Deviations / notes, stated

- Presidio: the blueprint names "Presidio + Turkish recognizers". Presidio's
  value is its recognizer registry around an NLP engine — but spaCy ships no
  Turkish model (00 §2) and every clean path still meant building the TR
  recognizers and the NER model ourselves. The engine here implements exactly
  the recognizer set + anonymizer semantics the acceptance lists, without the
  Presidio dependency chain; if a later issue wants Presidio's registry
  around these same recognizers, they plug in as custom recognizers
  unchanged. Recorded here rather than silently decided — reviewer may
  overrule.
- `/data` server use: everything ran inside `/data/intake` (venv, HF cache,
  models, logs) under `bin/guard.sh` floors (disk ≥300G+12%, RAM ≥64G, load
  ≤0.75/core) with `safe_run.sh` polling every 15 s — nothing else on the box
  touched.
- The in-house `deid-tr` project (/data/PIIMa, Apache-2.0, pre-alpha, "masks
  no names") was found on the box; this model artefact is exactly the names
  tier it lacks — flagged to the owner as a reuse opportunity.
