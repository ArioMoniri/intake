## Red runs (three genuinely red signals)

1. Unit: flows.spec restructure written first — old section ids
   (`complaint/duration/extra`) fail against the standardized builder until
   `buildNote` was rewritten.
2. **Device (found by the smoke run, invisible to unit tests):**
   `router.push` into the visits tab silently did nothing — under NATIVE
   tabs, a tab needs an explicit inner `Stack` layout; without
   `(tabs)/visits/_layout.tsx` cross-tab pushes are dropped. Deep links to
   the route were equally inert.
3. **Device:** the language toggle flipped its own chip but no other text —
   `t()` reads a module-level catalog, so screens that consume no session
   state never re-render. Fixed by keying the root navigator on the active
   locale (full remount on switch).
