## What the tests pin

- **TCKN checksum** (published algorithm) — a checksum-valid TCKN in free text
  becomes `[TCKN]`; an arbitrary 11-digit number survives. The checksum is
  what makes this a TCKN redactor rather than a number shredder.
- **05x phone** (with and without the leading zero) → `[PHONE]`; **TR IBAN**
  (TR + 24 digits) → `[IBAN]`; fixture log lines come out clean.
- **Collector config tested from its own committed YAML** — the test extracts
  the `replace_all_patterns` statements from
  infra/observability/otel-collector.yaml and runs those exact patterns over
  the fixture logs. The config cannot drift from what is tested.
- **Names allow-list** — structured attributes are restricted to a closed set
  both app-side (`ALLOWED_LOG_ATTRIBUTES` in the JSON formatter: an attribute
  like `patient_name` never reaches a log line) and pipeline-side
  (`keep_keys` in the collector). Free-text NER-based name scrubbing is
  INT-015's Presidio service, deliberately not duplicated here.
- **Context propagation** — `bind_log_context` hashes the session id at the
  boundary (sha256, 16 hex chars; the raw value is never stored or logged —
  asserted), and JSON lines carry tenant_id/protocol_hash/prompt_version plus
  trace_id/span_id from the active span.
- **Local-only default** — `setup_otel` wires an OTLP exporter only when
  `OTEL_EXPORTER_OTLP_ENDPOINT` is set; CI stays vendor-free and no default
  network sink exists (vendor scan green).
