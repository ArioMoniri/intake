# CD-04 — Turkish hedge to answer-state table

Scope: simulated-patient stress testing only (owner decision D18, 2 Oct 2026). A licensed physician's review is required before any real patient.

## Question

When the answer to a scripted red-flag question is hedged, qualified, double-negated or 'bilmiyorum', which answer state does it take, per rule, given that it may never become ASKED_ABSENT?

## Decision

A hedged or qualified answer to a scripted rule question is UNCLEAR or PRESENT_QUALIFIED, never ASKED_ABSENT; only a plain negative ('hayır', 'yok', 'olmadı') to the scripted question itself is ASKED_ABSENT, and the matcher tests every entry below before it tests a plain negative, so 'yok gibi' never reads as 'yok'. PRESENT_QUALIFIED is not an eighth answer state: it is ASKED_PRESENT carrying the qualifier as an annotation, so it evaluates as present for the rule and the qualifier is carried into the note. UNCLEAR reads Unknown and triggers the slot's follow_up_tr once; an UNCLEAR on any CD-01 feature slot that survives the follow-up raises a labelled CD-08 clinic-inbox item (kind chest_pain_arms_unresolved), pinned to the note and never dropped, because under three-valued logic it can leave both chest-pain arms silent. The CKM screening archetype's presence value set (Yes / No / Unknown / Unsure) is the basis for keeping 'bilmiyorum' and every hedge out of No. For chest pain the NICE CG95 definition (pain or discomfort) makes a qualified pain or a discomfort present, and NICE CG95 1.2.1.1 and 1.2.1.7 make a pain that has passed still clinically present, to be dated by the anchor question (CD-05). The mapping is per rule and per slot: 'biraz' affirms breathlessness, which NICE names without a qualifier. On associated.diaphoresis NICE names marked sweating, so 'biraz' does not match the guideline feature, yet it is still PRESENT_QUALIFIED (qualifier mild_not_marked): as UNCLEAR it would leave both arms silent when no other feature is present, while a plain 'hayır' fires SARI_K1, so admitting a little sweating would be treated as less acute than denying it. That monotonicity argument is this author's (inference_disclosure), not NICE's. Two of the three files/04 §8.2 adversarial strings concern syncope and bleeding probes that no active rule reads; they take the UNCLEAR floor (which still arms the probe, CD-03) and whether they should be PRESENT_QUALIFIED stays draft_needs_source. An unmatched hedge is UNCLEAR.

**Why a hedge resolves at once.** CD-05 resolves an unresolved anchor to the reference day, the day of NICE's emergency-referral bands (CG95 1.2.1.7). A follow-up after "bilmiyorum" can only move the anchor to a less acute day. It delays the evaluation by a turn and invites a guess from a patient who has said they do not know. An off-choice answer such as "dün akşam" is different. It carries information the closed choice can sharpen, because whether it falls inside twelve hours depends on the reference time.

**Safety direction.** Every round-3 change resolves at least as acutely as before. A hedge reaches the most acute day without a turn that could only lower it. A negative to the timing question can no longer silence both chest-pain arms.
