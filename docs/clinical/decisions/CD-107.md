# CD-107 — Sourcing the two draft rules of base.life_threat

Scope: simulated-patient stress testing only (owner decision D18, 2 Oct 2026). A licensed physician's review is required before any real patient. No `clinical_signoff` field is touched (D17), and HB-C1 stays open. A paediatrician signs the airway rule.

Origin: owner, 17 Nov 2026, in chat: *"yes source the 15 red flag rules"* (INT-615).

## Question

The owner asked for the draft red-flag rules of `base.life_threat` to be sourced.

- For each draft rule, which current guideline states its trigger, threshold and level, quoted from a committed snapshot?
- Can the rule leave `draft_needs_source` without relaxing it (CLAUDE.md invariant 7)?

## Decision

### The count: two draft rules in the life-threat pack; fifteen across the compile

`files/protocols/base.life_threat.yaml` holds four rules:

| rule | status |
|---|---|
| `rf.chest_pain_cardiac_features` | active (EK-4) |
| `rf.chest_pain_no_cardiac_history` | active (EK-4) |
| `rf.paediatric_airway_obstruction` | **draft_needs_source** |
| `rf.crisis_disclosure_signposting` | **draft_needs_source** |

The fifteen the owner was told about is the compiler's count. `protocols compile --pack base.intake --life-threat files/protocols/base.life_threat.yaml` refuses fifteen draft rules (`DRAFT_RULE_NOT_SERVED`):

- the two above;
- the thirteen `red_flags` families of `packages/protocols/base/intake.yaml`: `rf.chest_pain_acute`, `rf.stroke_fast`, `rf.dyspnoea_rest`, `rf.anaphylaxis`, `rf.severe_bleeding`, `rf.suicidal_intent`, `rf.sepsis_like`, `rf.thunderclap_headache`, `rf.pregnancy_bleeding_pain`, `rf.fever_high_persistent`, `rf.weight_loss_unintentional`, `rf.new_neuro_deficit_subacute`, `rf.suicidal_ideation_passive`.

Those thirteen are skeletons, not rules with one unsourced value. Each has a pending trigger and an unset level, and no register or action scripts. Each names its own blockers:

- HB-C2 and HB-C7 for most;
- HB-C4 (obstetric input) for pregnancy;
- HB-L2 (C-SSRS licence) and HB-C8 (escalation policy) for the two suicide families.

Sourcing them means authoring them, which is new red-flag semantics and outside the life-threat brief. INT-615 does not author them.

### rf.paediatric_airway_obstruction: trigger set sourced, rule stays draft

The trigger set now has a paediatric source. **RCH Melbourne, *Acute upper airway obstruction*** (PIC endorsed, last updated March 2021) names each of the four parent-reportable features:

| gate feature | RCH |
|---|---|
| `stridor_reported` | "Stridor", under moderate obstruction |
| `tripod_position` | "Sniffing or tripod position", under severe to complete obstruction |
| `drooling_unable_to_swallow` | "Dysphagia and drooling" (retropharyngeal abscess); "Pooling of secretions, drooling" (epiglottitis) |
| `muffled_voice` | "Hot potato/muffled voice" (quinsy); "Muffled voice" (epiglottitis) |

RCH's key point, letting the child keep a position of their choice and avoiding distress, also supports the rule's CALM delivery as it is authored.

EK-4, the binding Turkish triage table, names airway obstruction risk in Kırmızı Kategori 1. It names *severe stridor or swallowing difficulty with airway obstruction risk* in Kategori 2.

The rule still stays `draft_needs_source`. No committed source settles three things:

1. **Level.** The rule is `KIRMIZI_K1`, but EK-4 prints the two features it names, stridor and swallowing difficulty, in Kategori 2. Lowering the rule to K2 would relax it, which invariant 7 forbids an agent to do. Keeping K1 on EK-4's general Kategori 1 line is a reading, not a quote. The level stays as authored, and the physician decides.
2. **Age band.** The gate reads `subject.age_years < 18`. Neither RCH nor EK-4 states an upper age bound. The committed WHO IMCI chart covers 2 months up to 5 years, and adopting it would narrow the rule.
3. **Stridor qualifier.** RCH lists intermittent stridor under *mild* obstruction, and EK-4 says *severe* stridor. The gate fires on any reported stridor, which is the more sensitive reading. Qualifying it would narrow the rule, which is the physician's call. LT-03-N already guards the croup near miss.

### rf.crisis_disclosure_signposting: stays draft

No guideline supplies a Turkish crisis lexicon. It has to be authored by a clinician (HB-C17), and the escalation policy the rule hands off to does not exist (HB-C8).

### The pack file is not edited

No rule changes status, so an edit would void the D23 synthetic signature with no rule to show for it. Narrowing the airway `source_gap` text to the three items above is folded into the one re-sign that follows the physician's sign-off.

Status: `active`, with `level`, `age_band`, `stridor_qualifier` and `crisis_rule` draft_needs_source. Machine-readable form: `packages/protocols/decisions/CD-107.yaml`.
