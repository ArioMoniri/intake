# CD-06 — Staleness windows per document class

Scope: simulated-patient stress testing only (owner decision D18, 2 Oct 2026). A licensed physician's review is required before any real patient.

## Question

For each document class (lab result, imaging report, discharge summary, medication list or prescription, ECG, vaccination record, pathology report), how old may an item be and still be eligible to inform a slot, and is an undated item ever eligible?

## Decision

No retrieved current guideline states a recency window for any of the seven classes as a criterion for using a prior document, so every window stays draft_needs_source and no number is supplied. Until a window is signed, a document of that class can only arm a probe and be shown to the clinician with its date (CD-02, CD-03); it never fills a slot. One part is decided: an undated item is never slot-eligible, because a value whose time is unknown cannot be placed against a rule's tense window (the engine reads an undated anchor as Unknown) and NICE CG95 makes the time since the event part of interpreting a result. For the ECG class one boundary is also recorded: NICE CG95's ECG criterion refers to the resting 12-lead ECG of the current assessment, taken as soon as possible, so a stored ECG document can never stand in for it, whatever window is later signed.

## Near-miss tests that pin it

- `undated_doc_not_slot_eligible` — positive: a dated document may arm a probe. Near-miss negative: the same document without a date neither arms an anchor nor fills any slot.
- `unsigned_window_never_fills` — positive: a dated lab result is shown to the clinician with its date. Near-miss negative: while the lab window is pending, the same result does not fill any slot.
- `stored_ecg_is_not_the_assessment_ecg` — positive: an uploaded ECG is shown with its date. Near-miss negative: it never sets any value that a rule reads as the current ECG.

## What stays draft_needs_source and why

Every window stays draft_needs_source: none of the retrieved sources states how old a reused document of any of the seven classes may be. NICE NG5 1.3.3 was considered and rejected, because it is a deadline for performing reconciliation, not a staleness window. Decided: undated items are never slot-eligible, and documents only add or arm.
