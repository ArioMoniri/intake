# CD-17 — Fiziksel tıp ve rehabilitasyon: one function question, with the open detail as its follow-up

Scope: simulated-patient stress testing only (owner decision D18, 2 Oct 2026). A licensed physician's review is required before any real patient.

## Question

V-FTVR-5: two function questions overlap, so the patient hears both:

- fiziksel tıp Q4 is open: how much the problem affects daily tasks, walking and self-care;
- cluster.medical `gunluk_islev_kisitlanmasi` is yes/no: difficulty with daily tasks.

Should the pack keep both function questions, or only one?

## Decision

Keep one function fact, asked once, and keep the rehabilitation detail as its follow-up.

Function is a core outcome in this population. NICE NG59 1.3.8 makes treatment that has "not improved pain or function" the threshold for the next intervention. Asking the same fact twice under two ids, though, costs a turn and invites two answers that disagree.

The resolver's merge rule settles the mechanics: a different id for the same fact is asked twice, and a branch slot with the same id replaces the cluster slot. So:

- **Q4** adopts the cluster's id, type, ask and follow-up verbatim (`gunluk_islev_kisitlanmasi`, boolean), and the cluster ask is replaced in place;
- **Q4a** (`zorlanilan_gunluk_isler`) is a new gated open item that carries the rehabilitation detail Q4 had (walking and self-care). It is asked only after a yes.

A patient without a limitation hears one question. A patient with a limitation hears the yes/no question, then names the activities.

The "ne ölçüde" (how much) wording is dropped. Grading the degree of limitation is a validated-instrument decision (ODI or HAQ type) that this pack does not make.

An override keeps the cluster slot's position, while a new pack-native child is appended later. Q4a is therefore worded to stand on its own, without pointing back to Q4.
