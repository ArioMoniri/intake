### Decisions locked in this blueprint (change via ADR, not ad-hoc)
- **Mobile:** Expo SDK 57 (RN 0.86, React 19.2, New Architecture only — not SDK 56, which has a Hermes V1 memory regression), expo-router native tabs, TypeScript strict, dev builds (not Expo Go), EAS.
- **Backend:** Python 3.12 / FastAPI / Postgres 16 + pgvector / Redis / Celery; **LiveKit Agents** for realtime voice; EHRbase (openEHR) + HAPI FHIR (R4) in Docker; MinIO for documents; everything self-hostable in Türkiye.
- **Voice runtime (v1.1):** two layers per `qwen-audio-agent` — a Realtime Talker with exactly six tools that never blocks, and a Clinical Backend Agent behind a per-session FIFO Work queue; Backend speech is delivered only at a safe insertion window; only a rules-engine RED may preempt. Scripted protocol questions are pre-synthesised (clip cache, 0 ms TTS); ask-ahead/reconcile-behind keeps the flow. Three profiles: `cascade_fast` (default: Soniox stt-rt-v5 + TTS v2, LiveKit TurnDetector v1, preemptive generation; 450–700 ms p50), `s2s_cloud` (GPT-Realtime-2 / Gemini 3.1 Flash Live; opt-in, eval-gated), `residency_tr` (Qwen3-ASR + vLLM + Chatterbox v3, all in Türkiye). Inworld voice profiling remains an optional consented affect tap.
- **LLM:** provider-agnostic gateway with structured outputs; Claude-class models for extraction/note quality in cloud profiles; Qwen3-30B-A3B or MedGemma 27B (v1; MedGemma 1.5 is 4B-only) on vLLM for the TR-residency profile. The Talker uses a small cached-prompt model for dynamic speech only.
- **Coverage & learning (v1.2):** all MHRS branches resolve to one of nine clinician-reviewed cluster packs; deep packs grow by volume; L0 generated packs are never served. Per-patient learning is deterministic and patient-visible; cross-patient learning is proposal-only with clinician approval and canary rollouts (ADR-013/014).
- **Parallel psychiatric signals (v1.2):** affect/voice profiling, linguistic markers and (research-flagged) acoustic biomarkers run in read-only observer lanes beside the conversation, never on the critical path, never writing triage (ADR-012).
- **Operability (v1.2):** `apps/admin-web` + metrics catalogue as code + probed self-hosting registry; OTel + Grafana/SigNoz, Langfuse, Unleash, Keycloak, Argo CD — all self-hosted; release blocked if a PHI-path component lacks a self-hosted fallback (ADR-015/016). CSAT, NPS, wait times and clinician pulse are tracked from P1.
- **Delivery (v1.4):** everything ships as **one issue → one PR** with tests-first evidence, `no_placeholders`/`evidence_check` CI gates, human-approval labels for clinical/legal/vendor/GPU decisions, and a loop that never fakes a blocked dependency (ADR-019).
- **Firm legal frame (v1.4):** `06` cites each instrument (KVKK 6698+7499, transfer regulation 2024, KSVY, HHY, 1219, SBYS 2022/2026, Uzaktan Sağlık 2022, Tıbbi Cihaz Yönetmeliği/MDR Rule 11, 7545, Genelge 2019/12, 5651, 6502/6563-İYS, 805) and binds every obligation to backlog issues; the medical-device boundary is enforced by the `device_functions` flag — Stage A clinical investigation at Acıbadem, Stage B CE Class IIa (ADR-020).
- **Security & monitoring (v1.3):** one baseline for every service — Keycloak/OTP + attestation + DPoP, OpenBao keys and secrets, envelope encryption + tokenized identifiers, mesh mTLS, WAF + egress allow-list, de-identification before cloud calls, signed images and protocol packs, WORM audit; `/healthz` `/readyz` `/metrics` `/version` everywhere, OTel with redaction, SLOs + burn-rate alerts, synthetic probes, chaos/load gates; CI blocks on secrets, critical CVEs, unsigned artifacts, uncatalogued metrics (ADR-017/018).
- **Clinical truth:** openEHR compositions are canonical; FHIR R4 is the exchange format; Protocol Registry YAML DSL with `extends:` inheritance compiles to FHIR Questionnaire + openEHR template bindings.
- **Safety:** triage RED/YELLOW can only be set by the deterministic rules engine; LLMs extract, never escalate; only RED may interrupt speech. Patients never see diagnostic language. Raw audio is never persisted. ADR-009…011 lock the runtime boundary.
- **Turkish-first:** every string exists in `tr` before `en`; clinical copy reviewed by a clinician before release.
